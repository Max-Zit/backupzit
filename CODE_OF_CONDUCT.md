# Code of conduct

BackupZit is built for and with people who look after other people's data. Treat everyone in issues, discussions and pull requests with the same care.

**Expected:** be respectful and patient, assume good intent, keep discussions on topic, give and accept constructive criticism, and help newcomers.

**Not acceptable:** harassment, insults or personal attacks; discriminatory language or content; publishing other people's private information; sharing exploits for unfixed vulnerabilities in public instead of [reporting them privately](SECURITY.md); spam or advertising.

**Enforcement:** the maintainers may edit or remove comments, close threads and block participants who do not follow this code. Report problems to the maintainers through [GitHub](https://github.com/Max-Zit) — reports are handled confidentially.

This code applies in all BackupZit spaces on GitHub and wherever someone represents the project. It is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
