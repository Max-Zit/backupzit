Agents

An agent is installed on every machine you protect. It runs as a service, asks the console for work every 30 seconds and talks to the storage directly.

Supported systems

  • Windows 10, 11 and Windows Server 2016 and newer — Windows agent MSI.
  • Windows 7 SP1, Windows Server 2008 R2 SP1 and 2012 R2 — Windows agent — older systems MSI (…-legacy.msi), with the same features including VSS and disk images.
  • Debian, Ubuntu, AlmaLinux, Rocky Linux (64-bit).

Enrolling agents

  1. On the Agents page click Create enrollment token. A token is valid for 7 days and can be used for any number of machines.
  2. Copy the command for your platform and run it on the machine as administrator / root.
  3. The machine appears in the agent list within a minute.

Windows (MSI)

msiexec /i backupzit-agent.msi /qn SERVER="https://backup.example.local:8443" TOKEN="..." FINGERPRINT="SHA256:..."

The MSI can be deployed with Group Policy, Intune or any RMM tool. Without the properties it installs the service, which waits until you enroll it with backupzit-agent enroll.

Linux

apt install ./backupzit-agent_*.deb        # or: dnf install ./backupzit-agent-*.rpm
backupzit-agent enroll --server "https://backup.example.local:8443" --token "..." --fingerprint "SHA256:..."
systemctl enable --now backupzit-agent

Agent status

  • online — the agent contacted the console in the last 3 minutes.
  • offline — the machine is off, the service is stopped or the network is blocked. Scheduled backups are queued and start as soon as the agent comes back.
  • recovery — a machine booted from the recovery ISO, ready to receive a full-disk restore.

Upgrading

Install the newer MSI / package over the old one; the enrollment is kept. Installers are offered under Downloads on the Agents page.

Removing an agent

Remove on the Agents page deletes the agent and its jobs from the console. Backups on the storage are not deleted. Uninstall the software on the machine separately.

Where the agent keeps its configuration

  • Windows: C:\ProgramData\backupzit\agent.json (accessible only to SYSTEM and Administrators).
  • Linux: /etc/backupzit/agent.json (root only).

The file contains the agent's secret. Anyone who can read it can act as that agent, so keep these permissions.

Agent log

  • Windows: C:ProgramDataackupzitgent.log
  • Linux: journalctl -u backupzit-agent

Uninstalling

Windows: Settings → Apps → BackupZit Agent → Uninstall (or msiexec /x). Linux: apt remove backupzit-agent / dnf remove backupzit-agent. Then remove the agent in the console. Backups stay on the storage.
