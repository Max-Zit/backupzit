REST API

Povežite BackupZit sa RMM platformama, nadzorom (PRTG, Zabbix, Nagios, Uptime Kuma …) i sopstvenim skriptama.

Tokeni

Napravite token u Moj nalog → API tokeni. Dajte mu najnižu ulogu koja je dovoljna — Posmatrač za nadzor, Operater vraćanja da bi mogao i da pokreće bekape i testove vraćanja. Token se prikazuje jednom; šaljite ga u svakom zahtevu:

Authorization: Bearer bzt_...

Tokeni mogu da isteknu, može da ih opozove vlasnik ili administrator (Korisnici), i prestaju da rade kada se vlasnik onemogući. Radnje urađene tokenom pojavljuju se u dnevniku revizije sa imenom tokena.

Krajnje tačke

Svi odgovori su JSON. Osnovni URL: https://<konzola>:8443.

Metod i putanjaUlogaVraća
GET /api/v1/statusPosmatračUkupno stanje: agenti na mreži, neuspesi i upozorenja u 24 h, aktivna pokretanja, nepregledani sumnjivi bekapi, "ok": true|false
GET /api/v1/agentsPosmatračAgente sa OS-om, verzijom, stanjem na mreži i poslednjim kontaktom
GET /api/v1/jobs, GET /api/v1/jobs/{id}PosmatračPoslove sa rasporedom, sledećim pokretanjem i poslednjim rezultatom
POST /api/v1/jobs/{id}/runOperater vraćanjaPokreće posao odmah: {"run_id": 123} (202), ili 409 ako je pokretanje već aktivno
POST /api/v1/jobs/{id}/testOperater vraćanjaPokreće test vraćanja najnovijeg bekapa posla
GET /api/v1/runs?job=&agent=&status=&limit=PosmatračSkorašnja pokretanja, od najnovijeg (podrazumevano 100, najviše 1000)
GET /api/v1/runs/{id}PosmatračJedno pokretanje sa porukom, greškama i statistikom
GET /api/v1/report?period=&from=&to=&agent=&job=PosmatračIzveštaj za period: zbirovi, procenat uspešnosti i detalji po poslu
GET /api/v1/targetsPosmatračSkladišta (bez pristupnih podataka)

Periodi: today, yesterday, last7, last30, last90, thisweek, lastweek, thismonth, lastmonth, ili custom sa from=2026-09-01&to=2026-09-30.

Greške vraćaju {"error": "..."} sa 400 (loš zahtev), 401 (token nedostaje, neispravan je ili je istekao), 403 (preniska uloga), 404 ili 409.

Primeri

curl

curl -sk -H "Authorization: Bearer $BZ_TOKEN" https://backup.example.local:8443/api/v1/status
curl -sk -X POST -H "Authorization: Bearer $BZ_TOKEN" https://backup.example.local:8443/api/v1/jobs/7/run

PowerShell

$h = @{ Authorization = "Bearer $env:BZ_TOKEN" }
$s = Invoke-RestMethod -Uri https://backup.example.local:8443/api/v1/status -Headers $h -SkipCertificateCheck
if (-not $s.ok) { Write-Warning "BackupZit needs attention: $($s.failed_24h) failed backups" }

Koristite -k / -SkipCertificateCheck samo sa samopotpisanim sertifikatom konzole u pouzdanoj mreži, ili instalirajte sertifikat konzole na host za nadzor.

Provera za nadzor

Proveravajte /api/v1/status na svakih nekoliko minuta i uzbunite kada je ok false. Za proveru po poslu koristite /api/v1/jobs i uzbunite kada je last_status failed ili je last_finished stariji nego što se očekuje.
