REST API

Propojte BackupZit s platformami RMM, monitoringem (PRTG, Zabbix, Nagios, Uptime Kuma …) a vlastními skripty.

Tokeny

Token vytvoříte v Můj účet → Tokeny API. Dejte mu nejnižší roli, která stačí — Čtenář pro monitoring, Operátor obnovy, aby mohl také spouštět zálohy a testy obnovy. Token se zobrazí jen jednou; posílejte ho v každém požadavku:

Authorization: Bearer bzt_...

Tokeny mohou vypršet, může je odvolat vlastník nebo správce (Uživatelé) a přestanou fungovat, když je vlastník zakázán. Akce provedené tokenem se objeví v protokolu auditu s názvem tokenu.

Koncové body

Všechny odpovědi jsou v JSON. Základní URL: https://<konzole>:8443.

Metoda a cestaRoleVrací
GET /api/v1/statusČtenářCelkový stav: agenti online, chyby a varování za 24 h, aktivní běhy, nezkontrolované podezřelé zálohy, "ok": true|false
GET /api/v1/agentsČtenářAgenty se systémem, verzí, stavem online a posledním kontaktem
GET /api/v1/jobs, GET /api/v1/jobs/{id}ČtenářÚlohy s plánem, dalším během a posledním výsledkem
POST /api/v1/jobs/{id}/runOperátor obnovySpustí úlohu hned: {"run_id": 123} (202), nebo 409, pokud již běh probíhá
POST /api/v1/jobs/{id}/testOperátor obnovySpustí test obnovy nejnovější zálohy úlohy
GET /api/v1/runs?job=&agent=&status=&limit=ČtenářNedávné běhy, nejnovější první (výchozí 100, nejvýše 1000)
GET /api/v1/runs/{id}ČtenářJeden běh se zprávou, chybami a statistikou
GET /api/v1/report?period=&from=&to=&agent=&job=ČtenářPřehled za období: součty, úspěšnost a podrobnosti podle úloh
GET /api/v1/targetsČtenářCílová úložiště (bez přihlašovacích údajů)

Období: today, yesterday, last7, last30, last90, thisweek, lastweek, thismonth, lastmonth nebo custom s from=2026-09-01&to=2026-09-30.

Chyby vracejí {"error": "..."} s kódem 400 (chybný požadavek), 401 (token chybí, je neplatný nebo vypršel), 403 (příliš nízká role), 404 nebo 409.

Příklady

curl

curl -sk -H "Authorization: Bearer $BZ_TOKEN" https://backup.example.local:8443/api/v1/status
curl -sk -X POST -H "Authorization: Bearer $BZ_TOKEN" https://backup.example.local:8443/api/v1/jobs/7/run

PowerShell

$h = @{ Authorization = "Bearer $env:BZ_TOKEN" }
$s = Invoke-RestMethod -Uri https://backup.example.local:8443/api/v1/status -Headers $h -SkipCertificateCheck
if (-not $s.ok) { Write-Warning "BackupZit needs attention: $($s.failed_24h) failed backups" }

-k / -SkipCertificateCheck používejte jen s certifikátem konzole podepsaným sám sebou v důvěryhodné síti, nebo certifikát konzole nainstalujte na monitorovací hostitel.

Kontrola v monitoringu

Dotazujte se na /api/v1/status každých pár minut a upozorněte, když je ok false. Pro kontrolu jednotlivých úloh použijte /api/v1/jobs a upozorněte, když je last_status failed nebo je last_finished starší, než se čeká.
