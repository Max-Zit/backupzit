Referenční příručka příkazového řádku

Agent funguje i samostatně z příkazového řádku — pro skripty, pro obnovu bez konzole a pro nouzové situace. Spusťte backupzit-agent bez argumentů pro přehled a backupzit-agent <command> -h pro volby příkazu.

Repozitář a přihlašovací údaje

Každý příkaz přijímá --repo (nebo BACKUPZIT_REPO). Pro tajné údaje dávejte přednost proměnným prostředí. Repozitář agenta je <umístění úložiště>/<hostname>_<id> — viz sloupec repozitáře u běhu v Aktivitě nebo list pro obnovu.

UmístěníPřihlašovací údaje
D:\Backups\pc1, /mnt/backup/pc1—
sftp://user@host:22/pathBACKUPZIT_SFTP_PASSWORD nebo --sftp-key file; --sftp-hostkey SHA256:… (BACKUPZIT_SFTP_HOSTKEY)
s3://endpoint/bucket/prefix (?tls=false pro HTTP)BACKUPZIT_S3_ACCESS_KEY, BACKUPZIT_S3_SECRET_KEY, --s3-region; --s3-lock-days N zapisuje s Object Lock
smb://[domain;]user@host/share/pathBACKUPZIT_SMB_PASSWORD, --smb-domain
azure://account/container/path (?endpoint=URL pro suverénní cloudy, Azure Stack, Azurite)BACKUPZIT_AZURE_KEY nebo BACKUPZIT_AZURE_SAS
hardened://host:8500/pathBACKUPZIT_HARDENED_KEY, BACKUPZIT_HARDENED_FINGERPRINT
usb://LABEL/path (zástupné znaky: usb://BZBACKUP*/BackupZit)— (použije se připojený disk s touto jmenovkou svazku)

Šifrované repozitáře potřebují klíč pro obnovení v BACKUPZIT_PASSWORD (nebo --password).

Pohled k určitému okamžiku: na S3 s Object Lock a na zabezpečeném úložišti --as-of 2026-10-01T14:30 (nebo datum) ukáže repozitář tak, jak byl v tom okamžiku — jen pro čtení, k obnově poté, co byly zálohy smazány nebo přepsány.

Soubory a složky

PříkazCo dělá
initVytvoří nový repozitář (šifrovaný, pokud je zadáno heslo).
backup [--vss] [--exclude PATTERN]… [--tag TAG]… [--force] [--host NAME] PATH…Zálohuje soubory a složky. --vss čte ze stínové kopie svazku (Windows, správce); --force čte všechny soubory, i nezměněné.
snapshotsVypíše snímky s časem, hostitelem, velikostí a cestami.
ls SNAPSHOT|latest [PATH]Vypíše soubory ve snímku.
restore --target DIR [--include PATH]… [--verify] SNAPSHOT|latestObnoví soubory pod DIR (původní struktura složek se vytvoří znovu). --original je místo toho zapíše na původní místo a přepíše existující soubory.
check [--read-data]Zkontroluje strukturu repozitáře; s --read-data se každý bajt stáhne a ověří.

Obrazy disků (Windows)

PříkazCo dělá
disks [--json]Zobrazí disky a oddíly s jejich čísly.
image-backup --disk N [--partitions 1,2] [--no-vss]
image-backup --all-disks		Zálohuje celý disk nebo vybrané oddíly, nebo všechny interní disky v jednom snímku.
image-restore --target-disk N --yes-erase-target [--keep-offline] [--source-disk N] SNAPSHOT|latestZapíše obraz na disk; vymaže disk. --keep-offline, když je původní disk ve stejném počítači; --source-disk vybere disk ze zálohy všech disků.
image-ls [--disk N] --partition N SNAPSHOT|latest [\path]Vypíše soubory v oddílu NTFS v obrazu (--disk: zálohovaný disk, u záloh všech disků).
image-extract [--disk N] --partition N --target DIR SNAPSHOT|latest \path…Zkopíruje soubory a složky z oddílu v obrazu.

Systém Linux (bare metal, P2V)

PříkazCo dělá
system-backup [--exclude PATTERN]Zálohuje všechny místní souborové systémy a rozložení disků. Viz Záloha systému Linux.
system-show SNAPSHOT|latestZobrazí rozložení disků v záloze systému.
system-restore --target DEVICE [--new-hardware] [--rebuild-initramfs] --yes-erase-target SNAPSHOT|latestZnovu vytvoří systém na prázdném disku, logickém svazku nebo v souboru obrazu.

Windows: jiný hardware

PříkazCo dělá
prepare-hardware --disk N [--drivers DIR]Připraví obnovený disk Windows pro jiný hardware (zaváděcí ovladače, další ovladače, zaváděcí soubory) — totéž co volba obnovy, např. pro zopakování z ISO pro obnovu.

VMware ESXi (libovolný agent jako proxy; heslo v BACKUPZIT_VMWARE_PASSWORD)

PříkazCo dělá
vmware list --host H [--user root]Zobrazí VM hostitele, režim licence, otisky certifikátu a klíče SSH a datová úložiště.
vmware backup --host H [--vmid N,N]Zálohuje VM (výchozí: všechny) ze snímků; s Changed Block Tracking se čtou jen změněné bloky.
vmware restore --host H --vmid N [--new] [--name X] [--datastore DS] [--overwrite] [--start] SNAPSHOT|latestObnoví VM na místě (výchozí) nebo jako novou VM s --new. --overwrite nahradí disky existující VM; staré se ponechají přejmenované. Viz VMware ESXi.
esxi-nfs-servePoskytuje okamžité VM hostitelům ESXi přes NFS z /var/lib/backupzit/instant-esxi (Linux; spouští ho okamžitá obnova jako jednotku systemd backupzit-esxi-nfs).

Připněte hostitele pomocí --thumbprint SHA256:… a --ssh-host-key SHA256:… (zobrazí je vmware list).

Hyper-V (agent na hostiteli Hyper-V, jako správce)

PříkazCo dělá
hyperv listVypíše VM hostitele s jejich čísly BackupZit a složky pro obnovené disky.
hyperv backup [--vmid N,N]Zálohuje VM (výchozí: všechny) z produkčních kontrolních bodů.
hyperv restore --vmid N [--new] [--name X] [--folder DIR] [--overwrite] [--start] SNAPSHOT|latestObnoví VM na místě (výchozí) nebo jako novou VM s --new. --overwrite nahradí disky existující VM. Viz Hyper-V.

pve show, pve ls a pve extract fungují i se zálohami Hyper-V.

Proxmox VE (agent na hostiteli Proxmox)

PříkazCo dělá
pve listVypíše VM a kontejnery clusteru a úložiště použitelné pro obnovu.
pve backup [--vmid 100,200] [--exclude 300]Zálohuje hosty tohoto uzlu (výchozí: všechny) ze snímků Proxmoxu.
pve show SNAPSHOT|latestZobrazí hosty a disky v záloze VM.
pve ls --vmid N [--disk scsi0] [--volume ID] SNAPSHOT|latest [path]Vypíše oddíly a logické svazky disku hosta nebo soubory ve složce (NTFS, ext4, XFS, i na LVM).
pve extract --vmid N --target DIR [--volume ID] SNAPSHOT|latest path...Zkopíruje soubory a složky z disku hosta bez obnovy VM.
pve restore --vmid N [--new-vmid -1|N] [--name X] [--storage S] [--overwrite] [--start] SNAPSHOT|latestZnovu vytvoří hosta; --new-vmid -1 vezme další volné ID, --overwrite nahradí existujícího hosta se stejným ID. Viz Proxmox VE.
pve instant --vmid N [--new-vmid N] [--name X] SNAPSHOT|latestOkamžitá obnova: spustí VM během několika sekund, zatímco se její disky čtou ze zálohy (nová VM, ve výchozím stavu další volné ID).
pve instant-finish --vmid N --storage SPřesune disky okamžité VM na úložiště za běhu; poté už zálohu nepoužívá.
pve instant-discard --vmid NZastaví a smaže okamžitou VM i s jejími změnami.
nbd-serve --snapshot ID --vmid N --socket PATHPoskytuje disky VM ze zálohy jen pro čtení přes NBD na unixovém soketu (spouští ho okamžitá obnova jako jednotku systemd).

Microsoft SQL Server (agent na počítači se SQL Serverem)

PříkazCo dělá
sql list [--instance I]Vypíše databáze instance s modelem obnovení a velikostí.
sql backup [--instance I] [--db a,b] [--system] [--log] [--copy-only]Úplné zálohy (výchozí: všechny uživatelské databáze) nebo s --log zálohy transakčního logu do repozitáře.
sql showVypíše zálohy SQL Serveru v repozitáři s jejich rozsahy LSN.
sql restore --db NAME [--as NEW] [--replace] [--at TIME] SNAPSHOT|latestObnoví databázi z úplné zálohy a následných záloh logu, volitelně k určitému okamžiku. Viz SQL Server.

PostgreSQL a MySQL/MariaDB (agent na databázovém serveru)

PříkazCo dělá
pg list [--port P]Databáze místního clusteru a zda je zapnuta archivace WAL.
pg backup [--port P] [--db a,b] [--pitr | --wal]Úplná záloha (pg_basebackup, pg_dump každé databáze; --pitr nastaví archivaci WAL) nebo s --wal archivovaný WAL.
pg restore --db NAME|"(cluster)" [--as NEW] [--replace] [--at TIME | --latest] SNAPSHOT|latestObnoví databázi (z jejího výpisu nebo k určitému okamžiku) nebo celý cluster jako samostatnou instanci.
mysql listDatabáze a zda je zapnut binární log.
mysql backup [--db a,b] [--binlog]mysqldump každé databáze s její pozicí v binárním logu, nebo uzavřené binární logy.
mysql restore --db NAME [--as NEW] [--replace] [--at TIME | --latest] SNAPSHOT|latestNačte výpis a přehraje binární logy do určitého okamžiku. Viz Databáze.

Spravovaný režim

PříkazCo dělá
enroll --code BZ1-… [--force]Připojí agenta ke konzoli pomocí registračního kódu ze stránky Agenti (--force nahradí existující registraci). Starší forma --server URL --token T --fingerprint F stále funguje.
set-server https://address:8443Nasměruje registrovaného agenta na novou adresu konzole (stejný certifikát); poté restartujte službu agenta. Viz Agenti.
statusZobrazí, co běžící agent právě dělá, a jeho úlohy zálohování (ikona v oznamovací oblasti Windows ukazuje totéž).
service install|uninstall|start|stop|status|runSpravuje službu agenta (dělají to instalátory).
recoveryRežim obnovy, spouštěný automaticky ISO pro obnovu; na libovolném živém systému Linux: sudo backupzit-agent recovery --server URL --token CODE.
versionVypíše verzi.

Příklady

set BACKUPZIT_PASSWORD=XXXX-XXXX-...
set BACKUPZIT_S3_ACCESS_KEY=...
set BACKUPZIT_S3_SECRET_KEY=...
backupzit-agent snapshots --repo s3://s3.wasabisys.com/company-backups/backupzit/pc1_1a2b3c4d
backupzit-agent restore --repo s3://s3.wasabisys.com/company-backups/backupzit/pc1_1a2b3c4d --target D:\Restore --include C:\Users\ana\Documents latest
backupzit-agent check --repo s3://... --read-data

backupzit-agent disks
backupzit-agent image-ls --repo usb://BZBACKUP1/BackupZit/pc1_1a2b3c4d --partition 3 latest \Users
backupzit-agent snapshots --repo hardened://vault:8500/backupzit/pc1_1a2b3c4d --as-of 2026-10-01T14:00

Zabezpečené úložiště (backupzit-repo)

PříkazCo dělá
backupzit-repo serveSpustí službu (to dělá systemd).
backupzit-repo add-key NAMEVytvoří přístupový klíč (zobrazí se jednou).
backupzit-repo keys / remove-key NAMEVypsat / odvolat přístupové klíče.
backupzit-repo fingerprintOtisk certifikátu pro konzoli.
