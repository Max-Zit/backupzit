Problemen oplossen en veelgestelde vragen

Een agent wordt als offline getoond

  • Staat de machine aan en draait de dienst? Windows: Get-Service backupzit-agent; Linux: systemctl status backupzit-agent.
  • Kan de machine de console bereiken? Test-NetConnection backup-server -Port 8443 of curl -k https://backup-server:8443/login.
  • Agentlogboek: C:\ProgramData\backupzit\agent.log, op Linux /etc/backupzit/agent.log of journalctl -u backupzit-agent. "fingerprint mismatch" betekent dat het consolecertificaat is gewijzigd — registreer de agent opnieuw.

Een back-up is mislukt

Open de run in Activiteit; de melding noemt de oorzaak. Veelvoorkomende oorzaken:

Melding bevatOplossing
host key mismatch / fingerprintDe sleutel van de SFTP-server is gewijzigd of de vingerafdruk is verkeerd ingevoerd. Controleer met ssh-keygen -lf op de server.
permission denied / access deniedInloggegevens van de opslag of maprechten. Test de aanmelding met een SFTP/SMB-client.
no space left / quotaDe opslag is vol. Verkort het bewaarbeleid of voeg ruimte toe; verlopen back-ups maken na de volgende run ruimte vrij.
repository is lockedEen andere bewerking (bijv. opschonen) draait op dezelfde repository; de run probeert het 30 minuten lang opnieuw. Verouderde vergrendelingen verlopen automatisch.
wrong password / recovery keyDe repository is met een andere sleutel aangemaakt — controleer of de taak het juiste opslagdoel gebruikt.
bucket has no Object Lock enabledEr is onveranderlijkheid gevraagd voor een bucket zonder Object Lock. Maak een nieuwe bucket met Object Lock.

Back-up gemarkeerd als verdachtControleer de machine op ransomware of massaal verwijderen (bijv. een leeggemaakte gesynchroniseerde map). Is alles in orde (bijv. een geplande migratie), klik dan op de taakpagina op Gecontroleerd — bewaarbeleid hervatten.

Updates: "updates from the console need the Linux package of the console"De console is niet vanuit het deb/rpm-pakket geïnstalleerd (bijvoorbeeld de evaluatiemodus). Werk hem bij op dezelfde manier als hij is geïnstalleerd.

Updates: status rolled-backDe nieuwe versie startte niet, dus de vorige en de bijbehorende database zijn teruggezet. Het logboek van de mislukte start staat op de pagina Updates; stuur het naar support.
Besturingssysteem: "no supported package manager"Updates van het besturingssysteem worden ondersteund op Debian, Ubuntu (apt) en AlmaLinux, Rocky Linux, RHEL (dnf).
Consoleback-up: "the backup was made by a newer BackupZit"Installeer vóór het herstel op de nieuwe console de versie die de back-up heeft gemaakt, of een nieuwere.
Consoleback-up: "console backups need network storage"Kies een SFTP-, S3-, SMB-, Azure- of geharde-repositorydoel; een lokaal pad van een agent is vanaf de console niet bereikbaar.
"Te veel mislukte aanmeldingen"Uw adres is geblokkeerd na herhaalde verkeerde wachtwoorden: standaard 30 minuten, langer bij herhaalde blokkades. Een beheerder kan de blokkade opheffen onder Instellingen → Aanmelden en beveiliging. Op de server heft backupzit-server --unblock-ip all alle blokkades op. Accounts worden nooit permanent vergrendeld.
Telefoon voor tweestapsaanmelding kwijtGebruik een van de herstelcodes; anders zet een beheerder de tweestapsaanmelding terug op uw gebruikerspagina. De laatste beheerder kan zijn wachtwoord op de server terugzetten met backupzit-server --set-admin-password.
"your directory account is not in any BackupZit group"Voeg de gebruiker toe aan een van de groepen die zijn gekoppeld onder Instellingen → LDAP / Active Directory, of koppel meer groepen. Gebruik daar Test om de groepen te zien die voor een gebruiker worden gevonden.
API geeft 401 / 403401: token ontbreekt, is ingetrokken, verlopen of de eigenaar is uitgeschakeld. 403: de rol van het token is te laag voor het verzoek.

Een herstelde VM met Windows Server 2012 R2 / Windows 8.1 start niet op Hyper-V Gen 2 ("hash was denied (DBX)")Microsoft heeft de oude bootloader voor Secure Boot ingetrokken. Schakel Secure Boot uit voor die VM, of werk het systeem bij voordat u er een back-up van maakt.

Virtuele machines, Linux-systemen en nieuwe hardware

SituatieWat te doen
Proxmox: "the guest is running and one of its disks is on storage without snapshot support"Draaiende gasten hebben LVM-thin-, ZFS-, Ceph RBD- of qcow2-schijven nodig. Verplaats de schijf (Disk Action → Move Storage) of maak een back-up van de gast terwijl die gestopt is.
Hyper-V: de run meldt "crash-consistent"De gast kon zich niet voorbereiden op het controlepunt. Controleer in Windows-gasten dat de Hyper-V-integratieservices (Backup (volume shadow copy)) in de VM-instellingen zijn ingeschakeld. Installeer in Linux-gasten hyperv-daemons (RHEL) of linux-cloud-tools / hyperv-daemons (Debian/Ubuntu).
VMware: "SSH off" of "SSH to …: connection refused"Schakel SSH in op de ESXi-host: Host → Actions → Services → Enable Secure Shell (en laat het met de host starten). Herstelbewerkingen, en back-ups met de gratis licentie, hebben het nodig.
VMware: "changed block tracking is off and can be enabled … only while the VM is off"Gratis ESXi-licentie: sluit de VM één keer af en voer daarna de taak uit; BackupZit schakelt changed block tracking in en latere back-ups lezen alleen gewijzigde blokken.
VMware: "copy the disk on the datastore (needs free space …)"Draaiende VM's worden kort op hun datastore gekopieerd. Maak daar ruimte vrij (zoveel als de schijf gebruikt), of maak een back-up van de VM terwijl die uit staat.
VMware: "… is a snapshot delta disk"De VM heeft eigen snapshots. Verwijder of consolideer ze in de ESXi Host Client (Snapshots → Delete all).
VMware: "the ESXi certificate changed"De host is opnieuw geïnstalleerd of een andere machine antwoordt op zijn adres. Is dat verwacht, verwijder de host dan onder Agents en voeg hem opnieuw toe om het nieuwe certificaat te pinnen.
VMware: bestanden *.replaced-DATE.vmdk naast VM-schijvenDe oude schijven van een ter plaatse herstelde VM. Verwijder ze in de datastorebrowser zodra de herstelde VM werkt.
Hyper-V: bestanden *.replaced-DATE naast VM-schijvenDe oude schijven van een ter plaatse herstelde VM. Verwijder ze zodra de herstelde VM werkt.
Direct herstel in Proxmox: de VM start niet of hangtControleer de schijfserver: systemctl status backupzit-instant-ID en journalctl -u backupzit-instant-ID op de node. De back-upopslag moet bereikbaar blijven; als de repository niet gelezen kan worden, blijven de schijfleesacties van de VM hangen.
Direct herstel in Proxmox: "efidisk0 stays on storage backupzit-instant"QEMU kan de EFI-variabelenopslag niet verplaatsen terwijl de VM draait. Sluit de VM af en voer qm disk move ID efidisk0 STORAGE --delete 1 uit; dat hangt niet van de back-up af.
Proxmox: "runs on node X; install the BackupZit agent on X"De gast is gemigreerd. Installeer de agent op elke node en maak back-ups van de gasten van elke node met de agent van die node.
Proxmox-back-ups of -herstel traag, SFTP "connection lost", "message authentication code incorrect" op de opslagserverBekend probleem van Intel e1000e-netwerkkaarten in Proxmox-hosts (logboek: "Detected Hardware Unit Hang", "Reset adapter unexpectedly"). Schakel offloading uit: ethtool -K eno1 tso off gso off gro off en voeg het toe als post-up-regel van de interface in /etc/network/interfaces.
Bestanden bladeren: "stored on a local path of the agent"De console kan alleen back-ups op netwerkopslag lezen. Gebruik backupzit-agent pve ls/extract of image-ls/image-extract op de agent.
Herstel van Linux-systeem: "missing programs …"Installeer de genoemde pakketten op de herstellende machine, of start de BackupZit Linux-herstel-ISO, die ze bevat.
Herstelde Linux-machine heeft geen netwerkDe netwerkinstellingen waren gebonden aan het oude MAC-adres (netplan match: macaddress). Herstel met Andere hardware, of verwijder de match-regels in /etc/netplan/.
Herstelde Windows stopt met INACCESSIBLE_BOOT_DEVICEHerstel opnieuw met Herstellen op andere hardware, of start de herstel-ISO en voer backupzit-agent prepare-hardware --disk 0 [--drivers E:\Drivers] uit.
Een herstelde kopie van een machine verschijnt als de originele agentHerstel naar een nieuwe Proxmox-VM meldt de agent in de kopie automatisch af. Verwijder bij andere kopieën agent.json in de kopie en registreer die als nieuwe machine.

Het tray-pictogram ontbreektKlik op de pijl ^ naast de klok en sleep het BackupZit-pictogram naar de taakbalk, of start BackupZit Agent vanuit het menu Start.

Een back-up eindigt met "waarschuwing"

Sommige bestanden konden niet worden gelezen — meestal bestanden die door een toepassing zijn vergrendeld terwijl VSS niet beschikbaar is, of bestanden waarvoor de agent geen rechten heeft. De lijst staat op de runpagina. Al het andere is geback-upt.

Back-ups zijn traag

  • De eerste back-up leest en uploadt alles; latere lezen alleen gewijzigde bestanden en uploaden alleen nieuwe gegevens.
  • Controleer het netwerkpad naar de opslag (wifi, VPN, uploadsnelheid naar internet bij cloudopslag).
  • Sluit caches, tijdelijke bestanden en media uit die u niet nodig hebt.

Veelgestelde vragen

Kan ik NFS gebruiken?

Om een back-up te maken van een NFS- (of SMB-)share, maakt u een taak NAS / bestandsshare; een Linux-agent koppelt de export voor elke run. Om back-ups op NFS op te slaan, koppelt u de export op de agent (Linux: /etc/fstab) en gebruikt u een doel Lokaal / gekoppeld pad zoals /mnt/nfs-backup; voor Windows-machines is een SMB-doel de betere keuze.

Kan ik back-ups naar andere opslag verplaatsen?

Kopieer de repositorymap (of het bucketvoorvoegsel) zoals hij is — hij is op zichzelf staand — en voeg een opslagdoel toe dat met dezelfde herstelsleutel naar de nieuwe locatie wijst.

Verwijdert het verwijderen van een taak de back-ups?

Nee. Back-ups blijven op de opslag en blijven herstelbaar vanuit Activiteit of de opdrachtregel.

Wat gebeurt er als de console uitvalt?

Er starten geen nieuwe geplande back-ups tot hij terug is; runs in de wachtrij gaan daarna verder. Herstel is altijd mogelijk vanaf de opdrachtregel met het herstelblad.

Hoeveel ruimte hebben back-ups nodig?

Voor de eerste back-up ongeveer de grootte van de gegevens na compressie, plus de dagelijkse wijzigingen voor elke bewaarde dag. De pagina Rapporten toont hoeveel er per taak is geüpload.
