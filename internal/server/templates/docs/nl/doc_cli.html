Opdrachtregelreferentie

De agent werkt ook zelfstandig vanaf de opdrachtregel: voor scripts, voor herstel zonder de console en voor noodgevallen. Voer backupzit-agent zonder argumenten uit voor een overzicht en backupzit-agent <command> -h voor de opties van een opdracht.

Repository en referenties

Elke opdracht accepteert --repo (of BACKUPZIT_REPO). Gebruik voor geheimen bij voorkeur omgevingsvariabelen. De repository van een agent is <opslaglocatie>/<hostname>_<id> — zie de repositorykolom van een uitvoering in Activiteit, of het herstelblad.

LocatieReferenties
D:\Backups\pc1, /mnt/backup/pc1—
sftp://user@host:22/pathBACKUPZIT_SFTP_PASSWORD of --sftp-key file; --sftp-hostkey SHA256:… (BACKUPZIT_SFTP_HOSTKEY)
s3://endpoint/bucket/prefix (?tls=false voor HTTP)BACKUPZIT_S3_ACCESS_KEY, BACKUPZIT_S3_SECRET_KEY, --s3-region; --s3-lock-days N schrijft met Object Lock
smb://[domain;]user@host/share/pathBACKUPZIT_SMB_PASSWORD, --smb-domain
azure://account/container/path (?endpoint=URL voor soevereine clouds, Azure Stack, Azurite)BACKUPZIT_AZURE_KEY of BACKUPZIT_AZURE_SAS
hardened://host:8500/pathBACKUPZIT_HARDENED_KEY, BACKUPZIT_HARDENED_FINGERPRINT
usb://LABEL/path (jokertekens: usb://BZBACKUP*/BackupZit)— (de aangesloten schijf met dat volumelabel wordt gebruikt)

Versleutelde repositories hebben de herstelsleutel nodig in BACKUPZIT_PASSWORD (of --password).

Weergave op een tijdstip: op S3 met Object Lock en op een geharde repository toont --as-of 2026-10-01T14:30 (of een datum) de repository zoals die op dat moment was — alleen-lezen, om te herstellen nadat back-ups zijn verwijderd of overschreven.

Bestanden en mappen

OpdrachtWat het doet
initMaakt een nieuwe repository (versleuteld als een wachtwoord is opgegeven).
backup [--vss] [--exclude PATTERN]… [--tag TAG]… [--force] [--host NAME] PATH…Maakt een back-up van bestanden en mappen. --vss leest uit een volumeschaduwkopie (Windows, beheerder); --force leest alle bestanden, ook ongewijzigde.
snapshotsToont snapshots met tijd, host, grootte en paden.
ls SNAPSHOT|latest [PATH]Toont de bestanden in een snapshot.
restore --target DIR [--include PATH]… [--verify] SNAPSHOT|latestHerstelt bestanden onder DIR (de oorspronkelijke mapstructuur wordt nagebouwd). --original schrijft ze in plaats daarvan terug naar hun oorspronkelijke locatie en overschrijft bestaande bestanden.
check [--read-data]Controleert de structuur van de repository; met --read-data wordt elke byte gedownload en gecontroleerd.

Schijfimages (Windows)

OpdrachtWat het doet
disks [--json]Toont schijven en partities met hun nummers.
image-backup --disk N [--partitions 1,2] [--no-vss]
image-backup --all-disks		Maakt een back-up van een hele schijf of gekozen partities, of van alle interne schijven in één snapshot.
image-restore --target-disk N --yes-erase-target [--keep-offline] [--source-disk N] SNAPSHOT|latestSchrijft een image naar een schijf; wist de schijf. --keep-offline wanneer de oorspronkelijke schijf in dezelfde machine zit; --source-disk kiest de schijf uit een back-up van alle schijven.
image-ls [--disk N] --partition N SNAPSHOT|latest [\path]Toont de bestanden in een NTFS-partitie in een image (--disk: de gebackupte schijf, bij back-ups van alle schijven).
image-extract [--disk N] --partition N --target DIR SNAPSHOT|latest \path…Kopieert bestanden en mappen uit een partitie in een image.

Windows: andere hardware

VMware ESXi (elke agent als proxy; wachtwoord in BACKUPZIT_VMWARE_PASSWORD)

OpdrachtWat het doet
vmware list --host H [--user root]Toont de VM's van de host, de licentiemodus, de vingerafdrukken van certificaat en SSH-sleutel, en de datastores.
vmware backup --host H [--vmid N,N]Maakt een back-up van VM's (standaard: alle) vanuit snapshots; met Changed Block Tracking worden alleen gewijzigde blokken gelezen.
vmware restore --host H --vmid N [--new] [--name X] [--datastore DS] [--overwrite] [--start] SNAPSHOT|latestHerstelt een VM ter plaatse (standaard) of als nieuwe VM met --new. --overwrite vervangt de schijven van een bestaande VM; de oude blijven hernoemd bewaard. Zie VMware ESXi.
esxi-nfs-serveBiedt de directe VM's van ESXi-hosts via NFS aan vanuit /var/lib/backupzit/instant-esxi (Linux; gestart door direct herstel als systemd-unit backupzit-esxi-nfs).

Pin de host met --thumbprint SHA256:… en --ssh-host-key SHA256:… (getoond door vmware list).

Hyper-V (agent op de Hyper-V-host, als beheerder)

OpdrachtWat het doet
hyperv listToont de VM's van de host met hun BackupZit-nummers, en de mappen voor herstelde schijven.
hyperv backup [--vmid N,N]Maakt een back-up van VM's (standaard: alle) vanuit productiecontrolepunten.
hyperv restore --vmid N [--new] [--name X] [--folder DIR] [--overwrite] [--start] SNAPSHOT|latestHerstelt een VM ter plaatse (standaard) of als nieuwe VM met --new. --overwrite vervangt de schijven van een bestaande VM. Zie Hyper-V.

pve show, pve ls en pve extract werken ook met Hyper-V-back-ups.

Proxmox VE (agent op de Proxmox-host)

OpdrachtWat het doet
pve listToont de VM's en containers van het cluster en de opslag die bruikbaar is voor herstel.
pve backup [--vmid 100,200] [--exclude 300]Maakt een back-up van de gasten van dit knooppunt (standaard: alle) vanuit Proxmox-snapshots.
pve show SNAPSHOT|latestToont de gasten en schijven in een VM-back-up.
pve ls --vmid N [--disk scsi0] [--volume ID] SNAPSHOT|latest [path]Toont de partities en logische volumes van een gastschijf, of de bestanden in een map (NTFS, ext4, XFS, ook op LVM).
pve extract --vmid N --target DIR [--volume ID] SNAPSHOT|latest path...Kopieert bestanden en mappen van een gastschijf zonder de VM te herstellen.
pve restore --vmid N [--new-vmid -1|N] [--name X] [--storage S] [--overwrite] [--start] SNAPSHOT|latestBouwt een gast opnieuw; --new-vmid -1 neemt de volgende vrije ID, --overwrite vervangt een bestaande gast met dezelfde ID. Zie Proxmox VE.
pve instant --vmid N [--new-vmid N] [--name X] SNAPSHOT|latestDirect herstel: start een VM binnen seconden terwijl de schijven uit de back-up worden gelezen (nieuwe VM, standaard de volgende vrije ID).
pve instant-finish --vmid N --storage SVerplaatst de schijven van een directe VM naar opslag terwijl ze draait; daarna gebruikt ze de back-up niet meer.
pve instant-discard --vmid NStopt en verwijdert een directe VM met haar wijzigingen.
nbd-serve --snapshot ID --vmid N --socket PATHBiedt de schijven van een VM in een back-up alleen-lezen aan via NBD op een Unix-socket (gestart door direct herstel als systemd-unit).

Voorbeelden

set BACKUPZIT_PASSWORD=XXXX-XXXX-...
set BACKUPZIT_S3_ACCESS_KEY=...
set BACKUPZIT_S3_SECRET_KEY=...
backupzit-agent snapshots --repo s3://s3.wasabisys.com/company-backups/backupzit/pc1_1a2b3c4d
backupzit-agent restore --repo s3://s3.wasabisys.com/company-backups/backupzit/pc1_1a2b3c4d --target D:\Restore --include C:\Users\ana\Documents latest
backupzit-agent check --repo s3://... --read-data

backupzit-agent disks
backupzit-agent image-ls --repo usb://BZBACKUP1/BackupZit/pc1_1a2b3c4d --partition 3 latest \Users
backupzit-agent snapshots --repo hardened://vault:8500/backupzit/pc1_1a2b3c4d --as-of 2026-10-01T14:00
