Microsoft 365: Exchange Online, OneDrive i SharePoint

BackupZit tworzy kopie skrzynek pocztowych (Exchange Online), kalendarzy, kontaktów, OneDrive i witryn SharePoint dzierżawy Microsoft 365 przez Microsoft Graph. Tylko odczytuje: w dzierżawie nic nie jest zmieniane ani usuwane. Dane pobiera dowolny agent z dostępem do internetu — na przykład agent na maszynie konsoli — i zapisuje je jak każdą kopię: z deduplikacją, szyfrowaniem, przechowywaniem, zadaniami kopii wtórnych i testami przywracania.

1. Rejestracja aplikacji w Microsoft Entra ID

Raz na dzierżawę, jako administrator globalny, w centrum administracyjnym Microsoft Entra:

  1. App registrations → New registration: nazwa np. BackupZit, Accounts in this organizational directory only, bez URI przekierowania. Zanotuj Application (client) ID i Directory (tenant) ID z przeglądu.
  2. Certificates & secrets → New client secret: wybierz okres ważności (np. 24 miesiące) i od razu skopiuj Value klucza tajnego — jest pokazywana tylko raz. Secret ID nie jest kluczem tajnym.
  3. API permissions → Add a permission → Microsoft Graph → Application permissions (nie delegated): User.Read.All, Mail.Read i Files.Read.All; dla kalendarzy i kontaktów także Calendars.Read i Contacts.Read, dla SharePoint Sites.Read.All.
  4. Kliknij Grant admin consent for …. Do tego czasu stan pokazuje Not granted, a kopie są odrzucane.

To wyłącznie uprawnienia do odczytu. Przywracanie do skrzynek w przyszłości wymaga uprawnień do zapisu, o które BackupZit nie prosi.

Aby ograniczyć aplikację do niektórych skrzynek, administrator Exchange może dodać application access policy lub zakres RBAC for Applications; konta spoza niego są wtedy zgłaszane jako nieczytelne.

2. Tworzenie zadania

W Zadania kopii utwórz zadanie typu Microsoft 365:

  • Agent: agent, który pobiera dane (Windows lub Linux, wersja 0.34.0 lub nowsza; 0.35.0 dla kalendarzy, kontaktów i SharePoint). Potrzebuje dostępu HTTPS do login.microsoftonline.com, graph.microsoft.com oraz, dla plików OneDrive i SharePoint, *.sharepoint.com.
  • Identyfikator katalogu (dzierżawy), Identyfikator aplikacji (klienta) i Klucz tajny klienta z kroku 1. Klucz jest przechowywany w postaci zaszyfrowanej.
  • Co kopiować: Poczta, OneDrive, Kalendarze i kontakty, Witryny SharePoint — w dowolnym połączeniu.
  • Konta: jeden adres w wierszu albo puste dla każdego konta dzierżawy, które ma skrzynkę lub OneDrive — konta dodane później są dołączane automatycznie; konta bez licencji są pomijane.
  • Witryny SharePoint: jeden adres witryny w wierszu (np. https://contoso.sharepoint.com/sites/sales) albo puste dla każdej witryny dzierżawy — witryny dodane później są dołączane automatycznie. Witryny osobiste (OneDrive) są pomijane; są kopiowane razem z kontami. Zadanie tylko dla SharePoint nie wymaga kont.

Zamiast wpisywać adresy, kliknij Wybierz z listy: konsola za pomocą podanej wyżej aplikacji odczytuje konta (oznaczając te bez licencji, które nie mają skrzynki ani OneDrive) i witryny SharePoint dzierżawy, a następnie wyświetla je do zaznaczenia; zaznaczone wypełniają pola. Podczas edycji zadania używany jest zapisany klucz tajny.

Przy zapisywaniu zadania konsola loguje się jako aplikacja i sprawdza uprawnienia, konta i witryny, więc błędny klucz tajny lub brak zgody administratora widać od razu. Konsola bez dostępu do internetu pomija sprawdzenie; pierwsza kopia pokaże wtedy, czy wszystko działa.

Co jest kopiowane

  • Poczta: wszystkie foldery poczty z podfolderami (Skrzynka odbiorcza, Elementy wysłane, Elementy usunięte, Archiwum, własne foldery…). Każda wiadomość jest zapisywana w całości z załącznikami w formacie MIME jako plik .eml, nazwany według czasu nadejścia i tematu, np. 2026-10-07 0621 Oferta na październik [3fa2c1d9e0].eml. Outlook, Thunderbird i większość programów pocztowych otwiera pliki .eml.
  • OneDrive: wszystkie pliki i foldery OneDrive konta, z czasem modyfikacji.
  • Kalendarze: każdy kalendarz konta; każde wydarzenie jako plik iCalendar (.ics) z czasem, miejscem, opisem, organizatorem, uczestnikami, przypomnieniem i — dla serii — jej cyklicznością, nazwany według początku i tematu, np. 2026-10-08 1000 Posiedzenie zarządu [8c1e…].ics. Outlook, Kalendarz Google i Thunderbird importują pliki .ics. Czasy są zapisywane w UTC.
  • Kontakty: kontakty i foldery kontaktów konta, każdy jako vCard (.vcf) z imionami i nazwiskami, adresami e-mail, numerami telefonów, adresami, firmą i notatkami.
  • SharePoint: każda biblioteka dokumentów każdej witryny (Dokumenty, Zasoby witryny i utworzone przez Ciebie biblioteki), ze wszystkimi folderami i plikami.

Nie są objęte: załączniki wydarzeń kalendarza, zdjęcia kontaktów, pojedynczo zmienione wystąpienia serii, listy i strony SharePoint (tylko biblioteki dokumentów), czaty Teams i wiadomości kanałów (pliki Teams są w SharePoint i są kopiowane razem z nim) oraz skrzynki współdzielone bez konta użytkownika.

Kopia zawiera jeden folder na konto — ana@contoso.com/Mail/Inbox/…, …/OneDrive/…, …/Calendar/Calendar/…, …/Contacts/… — oraz SharePoint/<site>/<library>/…. Pierwsza kopia pobiera wszystko; każda kolejna ponownie listuje foldery, ale pobiera tylko wiadomości i pliki nowe lub zmienione od poprzedniej kopii (przeczytane, oflagowane, przeniesione lub edytowane wiadomości liczą się jako zmienione) — niezmienione dane są brane z poprzedniej kopii. Microsoft ogranicza tempo odczytu przez aplikację; BackupZit czeka, gdy Microsoft o to prosi, i kontynuuje, więc pierwsza kopia dużych skrzynek może trwać godzinami.

Kopie dzierżawy są zapisywane we własnym repozytorium w magazynie (folder m365-<tenant ID>), więc pobierającego agenta można wymienić bez zaczynania od nowa.

Przywracanie

  • Przeglądaj pliki w uruchomieniu kopii: otwórz foldery poczty, OneDrive, kalendarze lub kontakty konta albo witrynę SharePoint, zaznacz wiadomości, wydarzenia, pliki lub foldery i pobierz je (jeden plik bez zmian, kilka jako ZIP) — otwórz pliki .eml w Outlooku lub przeciągnij je do skrzynki.
  • Przywróć do folderu na dowolnym agencie: wiadomości są zapisywane jako pliki .eml, wydarzenia jako .ics, kontakty jako .vcf, a pliki OneDrive i SharePoint w oryginalnej postaci, pod <folder>/<account>/… i <folder>/SharePoint/….

Bezpośrednie przywracanie do skrzynki lub OneDrive jest planowane; będzie zapisywać tylko do nowego folderu i nigdy niczego nie nadpisze ani nie usunie.

Rozwiązywanie problemów

  • AADSTS7000215 / invalid client secret: skopiowano nie Value klucza tajnego (lecz jego ID) albo klucz wygasł — utwórz nowy i wpisz go w zadaniu.
  • missing the application permissions lub Authorization_RequestDenied: dodaj uprawnienia jako uprawnienia aplikacji i kliknij Grant admin consent.
  • the account has no Exchange Online mailbox: konto nie ma licencji Exchange (albo jest kontaktem); usuń je z zadania.
  • Uruchomienie z ostrzeżeniami wymienia wiadomości lub pliki, których nie dało się odczytać (np. notes OneNote); reszta kopii jest kompletna.
