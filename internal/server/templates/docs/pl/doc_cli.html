Dokumentacja wiersza poleceń

Agent działa także samodzielnie z wiersza poleceń — do skryptów, do przywracania bez konsoli i w sytuacjach awaryjnych. Uruchom backupzit-agent bez argumentów, aby zobaczyć przegląd, oraz backupzit-agent <command> -h, aby zobaczyć opcje polecenia.

Repozytorium i dane uwierzytelniające

Każde polecenie przyjmuje --repo (lub BACKUPZIT_REPO). Do sekretów lepiej używać zmiennych środowiskowych. Repozytorium agenta to <lokalizacja magazynu>/<hostname>_<id> — zobacz kolumnę repozytorium uruchomienia w Aktywności lub arkusz odzyskiwania.

LokalizacjaDane uwierzytelniające
D:\Backups\pc1, /mnt/backup/pc1—
sftp://user@host:22/pathBACKUPZIT_SFTP_PASSWORD lub --sftp-key file; --sftp-hostkey SHA256:… (BACKUPZIT_SFTP_HOSTKEY)
s3://endpoint/bucket/prefix (?tls=false dla HTTP)BACKUPZIT_S3_ACCESS_KEY, BACKUPZIT_S3_SECRET_KEY, --s3-region; --s3-lock-days N zapisuje z Object Lock
smb://[domain;]user@host/share/pathBACKUPZIT_SMB_PASSWORD, --smb-domain
azure://account/container/path (?endpoint=URL dla chmur suwerennych, Azure Stack, Azurite)BACKUPZIT_AZURE_KEY lub BACKUPZIT_AZURE_SAS
hardened://host:8500/pathBACKUPZIT_HARDENED_KEY, BACKUPZIT_HARDENED_FINGERPRINT
usb://LABEL/path (symbole wieloznaczne: usb://BZBACKUP*/BackupZit)— (używany jest podłączony dysk o tej etykiecie woluminu)

Zaszyfrowane repozytoria wymagają klucza odzyskiwania w BACKUPZIT_PASSWORD (lub --password).

Widok z danej chwili: na S3 z Object Lock i w utwardzonym repozytorium --as-of 2026-10-01T14:30 (lub data) pokazuje repozytorium takie, jakie było w tym momencie — tylko do odczytu, aby odzyskać dane po usunięciu lub nadpisaniu kopii.

Pliki i foldery

PolecenieCo robi
initTworzy nowe repozytorium (zaszyfrowane, jeśli podano hasło).
backup [--vss] [--exclude PATTERN]… [--tag TAG]… [--force] [--host NAME] PATH…Tworzy kopię plików i folderów. --vss czyta z kopii w tle woluminu (Windows, administrator); --force czyta wszystkie pliki, także niezmienione.
snapshotsWyświetla migawki z czasem, hostem, rozmiarem i ścieżkami.
ls SNAPSHOT|latest [PATH]Wyświetla pliki w migawce.
restore --target DIR [--include PATH]… [--verify] SNAPSHOT|latestPrzywraca pliki pod DIR (odtwarzana jest oryginalna struktura folderów). --original zapisuje je zamiast tego w oryginalnej lokalizacji, nadpisując istniejące pliki.
check [--read-data]Sprawdza strukturę repozytorium; z --read-data każdy bajt jest pobierany i sprawdzany.

Obrazy dysków (Windows)

PolecenieCo robi
disks [--json]Pokazuje dyski i partycje z ich numerami.
image-backup --disk N [--partitions 1,2] [--no-vss]
image-backup --all-disks		Tworzy kopię całego dysku lub wybranych partycji albo wszystkich dysków wewnętrznych w jednej migawce.
image-restore --target-disk N --yes-erase-target [--keep-offline] [--source-disk N] SNAPSHOT|latestZapisuje obraz na dysk; kasuje dysk. --keep-offline, gdy oryginalny dysk jest w tej samej maszynie; --source-disk wybiera dysk z kopii wszystkich dysków.
image-ls [--disk N] --partition N SNAPSHOT|latest [\path]Wyświetla pliki w partycji NTFS w obrazie (--disk: skopiowany dysk, przy kopiach wszystkich dysków).
image-extract [--disk N] --partition N --target DIR SNAPSHOT|latest \path…Kopiuje pliki i foldery z partycji w obrazie.

System Linux (bare metal, P2V)

PolecenieCo robi
system-backup [--exclude PATTERN]Tworzy kopię wszystkich lokalnych systemów plików i układu dysków. Zobacz Kopia systemu Linux.
system-show SNAPSHOT|latestPokazuje układ dysków w kopii systemu.
system-restore --target DEVICE [--new-hardware] [--rebuild-initramfs] --yes-erase-target SNAPSHOT|latestOdtwarza system na pustym dysku, woluminie logicznym lub w pliku obrazu.

Windows: inny sprzęt

PolecenieCo robi
prepare-hardware --disk N [--drivers DIR]Przygotowuje przywrócony dysk Windows do innego sprzętu (sterowniki rozruchowe, dodatkowe sterowniki, pliki rozruchowe) — to samo co opcja przywracania, np. aby powtórzyć to z ISO odzyskiwania.

VMware ESXi (dowolny agent jako proxy; hasło w BACKUPZIT_VMWARE_PASSWORD)

PolecenieCo robi
vmware list --host H [--user root]Pokazuje maszyny wirtualne hosta, tryb licencji, odciski certyfikatu i klucza SSH oraz magazyny danych.
vmware backup --host H [--vmid N,N]Tworzy kopie maszyn wirtualnych (domyślnie: wszystkich) z migawek; z Changed Block Tracking czytane są tylko zmienione bloki.
vmware restore --host H --vmid N [--new] [--name X] [--datastore DS] [--overwrite] [--start] SNAPSHOT|latestPrzywraca maszynę wirtualną na miejscu (domyślnie) lub jako nową z --new. --overwrite zastępuje dyski istniejącej maszyny; stare są zachowywane pod zmienioną nazwą. Zobacz VMware ESXi.
esxi-nfs-serveUdostępnia natychmiastowe maszyny wirtualne hostom ESXi przez NFS z /var/lib/backupzit/instant-esxi (Linux; uruchamiane przez natychmiastowe odzyskiwanie jako jednostka systemd backupzit-esxi-nfs).

Przypnij host za pomocą --thumbprint SHA256:… i --ssh-host-key SHA256:… (pokazywane przez vmware list).

Hyper-V (agent na hoście Hyper-V, jako administrator)

PolecenieCo robi
hyperv listWyświetla maszyny wirtualne hosta z ich numerami BackupZit oraz foldery na przywrócone dyski.
hyperv backup [--vmid N,N]Tworzy kopie maszyn wirtualnych (domyślnie: wszystkich) z produkcyjnych punktów kontrolnych.
hyperv restore --vmid N [--new] [--name X] [--folder DIR] [--overwrite] [--start] SNAPSHOT|latestPrzywraca maszynę wirtualną na miejscu (domyślnie) lub jako nową z --new. --overwrite zastępuje dyski istniejącej maszyny. Zobacz Hyper-V.

pve show, pve ls i pve extract działają także z kopiami Hyper-V.

Proxmox VE (agent na hoście Proxmox)

PolecenieCo robi
pve listWyświetla maszyny wirtualne i kontenery klastra oraz magazyn dostępny do przywracania.
pve backup [--vmid 100,200] [--exclude 300]Tworzy kopie gości tego węzła (domyślnie: wszystkich) z migawek Proxmox.
pve show SNAPSHOT|latestPokazuje gości i dyski w kopii maszyn wirtualnych.
pve ls --vmid N [--disk scsi0] [--volume ID] SNAPSHOT|latest [path]Wyświetla partycje i woluminy logiczne dysku gościa lub pliki w folderze (NTFS, ext4, XFS, także na LVM).
pve extract --vmid N --target DIR [--volume ID] SNAPSHOT|latest path...Kopiuje pliki i foldery z dysku gościa bez przywracania maszyny.
pve restore --vmid N [--new-vmid -1|N] [--name X] [--storage S] [--overwrite] [--start] SNAPSHOT|latestOdtwarza gościa; --new-vmid -1 bierze następny wolny ID, --overwrite zastępuje istniejącego gościa o tym samym ID. Zobacz Proxmox VE.
pve instant --vmid N [--new-vmid N] [--name X] SNAPSHOT|latestNatychmiastowe odzyskiwanie: uruchamia maszynę w kilka sekund, podczas gdy jej dyski są czytane z kopii (nowa maszyna, domyślnie następny wolny ID).
pve instant-finish --vmid N --storage SPrzenosi dyski natychmiastowej maszyny do magazynu w trakcie jej działania; potem nie korzysta ona już z kopii.
pve instant-discard --vmid NZatrzymuje i usuwa natychmiastową maszynę wraz z jej zmianami.
nbd-serve --snapshot ID --vmid N --socket PATHUdostępnia dyski maszyny z kopii tylko do odczytu przez NBD na gnieździe Unix (uruchamiane przez natychmiastowe odzyskiwanie jako jednostka systemd).

Microsoft SQL Server (agent na maszynie z SQL Server)

PolecenieCo robi
sql list [--instance I]Wyświetla bazy danych instancji z modelem odzyskiwania i rozmiarem.
sql backup [--instance I] [--db a,b] [--system] [--log] [--copy-only]Pełne kopie (domyślnie: wszystkie bazy użytkownika) lub, z --log, kopie dziennika transakcji do repozytorium.
sql showWyświetla kopie SQL Server w repozytorium z ich zakresami LSN.
sql restore --db NAME [--as NEW] [--replace] [--at TIME] SNAPSHOT|latestPrzywraca bazę z pełnej kopii i następujących po niej kopii dziennika, opcjonalnie do danej chwili. Zobacz SQL Server.

PostgreSQL i MySQL/MariaDB (agent na serwerze baz danych)

PolecenieCo robi
pg list [--port P]Bazy lokalnego klastra i czy archiwizacja WAL jest włączona.
pg backup [--port P] [--db a,b] [--pitr | --wal]Pełna kopia (pg_basebackup, pg_dump każdej bazy; --pitr konfiguruje archiwizację WAL) lub, z --wal, zarchiwizowany WAL.
pg restore --db NAME|"(cluster)" [--as NEW] [--replace] [--at TIME | --latest] SNAPSHOT|latestPrzywraca bazę (z jej zrzutu lub do danej chwili) albo cały klaster jako osobną instancję.
mysql listBazy i czy dziennik binarny jest włączony.
mysql backup [--db a,b] [--binlog]mysqldump każdej bazy z jej pozycją w dzienniku binarnym lub zamknięte dzienniki binarne.
mysql restore --db NAME [--as NEW] [--replace] [--at TIME | --latest] SNAPSHOT|latestWczytuje zrzut i odtwarza dzienniki binarne do danej chwili. Zobacz Bazy danych.

Tryb zarządzany

PolecenieCo robi
enroll --code BZ1-… [--force]Łączy agenta z konsolą przy użyciu kodu rejestracji ze strony Agenci (--force zastępuje istniejącą rejestrację). Starsza forma --server URL --token T --fingerprint F nadal działa.
set-server https://address:8443Kieruje zarejestrowanego agenta na nowy adres konsoli (ten sam certyfikat); następnie uruchom ponownie usługę agenta. Zobacz Agenci.
statusPokazuje, co robi działający agent, oraz jego zadania kopii (ikona w zasobniku Windows pokazuje to samo).
service install|uninstall|start|stop|status|runZarządza usługą agenta (robią to instalatory).
recoveryTryb odzyskiwania, uruchamiany automatycznie przez ISO odzyskiwania; na dowolnym systemie Linux live: sudo backupzit-agent recovery --server URL --token CODE.
versionWyświetla wersję.

Przykłady

set BACKUPZIT_PASSWORD=XXXX-XXXX-...
set BACKUPZIT_S3_ACCESS_KEY=...
set BACKUPZIT_S3_SECRET_KEY=...
backupzit-agent snapshots --repo s3://s3.wasabisys.com/company-backups/backupzit/pc1_1a2b3c4d
backupzit-agent restore --repo s3://s3.wasabisys.com/company-backups/backupzit/pc1_1a2b3c4d --target D:\Restore --include C:\Users\ana\Documents latest
backupzit-agent check --repo s3://... --read-data

backupzit-agent disks
backupzit-agent image-ls --repo usb://BZBACKUP1/BackupZit/pc1_1a2b3c4d --partition 3 latest \Users
backupzit-agent snapshots --repo hardened://vault:8500/backupzit/pc1_1a2b3c4d --as-of 2026-10-01T14:00

Utwardzone repozytorium (backupzit-repo)

PolecenieCo robi
