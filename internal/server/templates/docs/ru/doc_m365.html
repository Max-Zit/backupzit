Microsoft 365: Exchange Online, OneDrive и SharePoint

BackupZit копирует почтовые ящики (Exchange Online), календари, контакты, OneDrive и сайты SharePoint клиента Microsoft 365 через Microsoft Graph. Он только читает: в клиенте ничего не изменяется и не удаляется. Данные скачивает любой агент с доступом в интернет — например, агент на машине консоли — и сохраняет их как любую копию: с дедупликацией, шифрованием, хранением, заданиями вторичного копирования и тестами восстановления.

1. Регистрация приложения в Microsoft Entra ID

Один раз для каждого клиента, от имени глобального администратора, в центре администрирования Microsoft Entra:

  1. App registrations → New registration: имя, например BackupZit, Accounts in this organizational directory only, без URI перенаправления. Запишите Application (client) ID и Directory (tenant) ID со страницы обзора.
  2. Certificates & secrets → New client secret: выберите срок действия (например, 24 месяца) и сразу скопируйте Value секрета — оно показывается только один раз. Secret ID — это не секрет.
  3. API permissions → Add a permission → Microsoft Graph → Application permissions (не delegated): User.Read.All, Mail.Read и Files.Read.All; для календарей и контактов также Calendars.Read и Contacts.Read, для SharePoint — Sites.Read.All.
  4. Нажмите Grant admin consent for …. До этого статус показывает Not granted, и копирование отклоняется.

Это только разрешения на чтение. Для будущего восстановления в почтовые ящики понадобятся разрешения на запись, которых BackupZit не запрашивает.

Чтобы ограничить приложение некоторыми почтовыми ящиками, администратор Exchange может добавить application access policy или область RBAC for Applications; учётные записи вне её будут отображаться как недоступные для чтения.

2. Создание задания

В Задания копирования создайте задание типа Microsoft 365:

  • Агент: агент, который скачивает данные (Windows или Linux, версия 0.34.0 или новее; 0.35.0 для календарей, контактов и SharePoint). Ему нужен HTTPS-доступ к login.microsoftonline.com, graph.microsoft.com и, для файлов OneDrive и SharePoint, к *.sharepoint.com.
  • Идентификатор каталога (клиента), Идентификатор приложения (клиента) и Секрет клиента из шага 1. Секрет хранится в зашифрованном виде.
  • Что копировать: Почта, OneDrive, Календари и контакты, Сайты SharePoint — в любом сочетании.
  • Учётные записи: по одному адресу в строке или пусто для всех учётных записей клиента, у которых есть почтовый ящик или OneDrive — учётные записи, добавленные позже, включаются автоматически; учётные записи без лицензии пропускаются.
  • Сайты SharePoint: по одному адресу сайта в строке (например, https://contoso.sharepoint.com/sites/sales) или пусто для всех сайтов клиента — сайты, добавленные позже, включаются автоматически. Личные сайты (OneDrive) не включаются; они копируются вместе с учётными записями. Заданию только для SharePoint учётные записи не нужны.

Вместо ввода адресов нажмите Выбрать из списка: консоль с помощью указанного выше приложения читает учётные записи (отмечая те, что без лицензии и не имеют ни почтового ящика, ни OneDrive) и сайты SharePoint клиента и показывает их для выбора; отмеченные заполняют поля. При изменении задания используется сохранённый секрет.

При сохранении задания консоль входит как приложение и проверяет разрешения, учётные записи и сайты, поэтому неверный секрет или отсутствие согласия администратора видны сразу. Консоль без доступа в интернет пропускает проверку; тогда первая копия покажет, работает ли всё.

Что копируется

  • Почта: все почтовые папки с подпапками (Входящие, Отправленные, Удалённые, Архив, ваши собственные папки…). Каждое письмо сохраняется целиком с вложениями в формате MIME как файл .eml с именем по времени получения и теме, например 2026-10-07 0621 Предложение на октябрь [3fa2c1d9e0].eml. Outlook, Thunderbird и большинство почтовых программ открывают файлы .eml.
  • OneDrive: все файлы и папки OneDrive учётной записи со временем изменения.
  • Календари: каждый календарь учётной записи; каждое событие — файл iCalendar (.ics) со временем, местом, описанием, организатором, участниками, напоминанием и — для серии — её повторением, с именем по началу и теме, например 2026-10-08 1000 Заседание правления [8c1e…].ics. Outlook, Google Календарь и Thunderbird импортируют файлы .ics. Время хранится в UTC.
  • Контакты: контакты и папки контактов учётной записи, каждый как vCard (.vcf) с именами, адресами электронной почты, телефонами, адресами, компанией и заметками.
  • SharePoint: каждая библиотека документов каждого сайта (Документы, Ресурсы сайта и созданные вами библиотеки) со всеми папками и файлами.

Не включается: вложения событий календаря, фотографии контактов, отдельно изменённые повторения серии, списки и страницы SharePoint (только библиотеки документов), чаты Teams и сообщения каналов (файлы Teams лежат в SharePoint и копируются вместе с ним), а также общие почтовые ящики без учётной записи пользователя.

Копия содержит по одной папке на учётную запись — ana@contoso.com/Mail/Inbox/…, …/OneDrive/…, …/Calendar/Calendar/…, …/Contacts/… — и SharePoint/<site>/<library>/…. Первая копия скачивает всё; каждая следующая снова перечисляет папки, но скачивает только письма и файлы, новые или изменённые с прошлой копии (прочитанные, помеченные, перемещённые или отредактированные письма считаются изменёнными), — неизменённые данные берутся из прошлой копии. Microsoft ограничивает скорость чтения приложением; BackupZit ждёт, когда Microsoft об этом просит, и продолжает, поэтому первая копия больших почтовых ящиков может занять часы.

Копии клиента хранятся в собственном репозитории в хранилище (папка m365-<tenant ID>), поэтому скачивающего агента можно заменить, не начиная заново.

Восстановление

  • Просмотр файлов в запуске копии: откройте почтовые папки, OneDrive, календари или контакты учётной записи либо сайт SharePoint, отметьте письма, события, файлы или папки и скачайте их (один файл как есть, несколько — архивом ZIP); откройте файлы .eml в Outlook или перетащите их в почтовый ящик.
  • Восстановить в папку на любом агенте: письма записываются как файлы .eml, события как .ics, контакты как .vcf, а файлы OneDrive и SharePoint — в исходном виде, в <folder>/<account>/… и <folder>/SharePoint/….

Прямое восстановление в почтовый ящик или OneDrive запланировано; оно будет записывать только в новую папку и никогда ничего не перезапишет и не удалит.

Устранение неполадок

  • AADSTS7000215 / invalid client secret: скопировано не Value секрета (а его ID), или срок его действия истёк — создайте новый и укажите его в задании.
  • missing the application permissions или Authorization_RequestDenied: добавьте разрешения как разрешения приложения и нажмите Grant admin consent.
  • the account has no Exchange Online mailbox: у учётной записи нет лицензии Exchange (или это контакт); удалите её из задания.
  • Запуск с предупреждениями перечисляет письма или файлы, которые не удалось прочитать (например, записную книжку OneNote); остальная часть копии полная.
