Мониторинг, отчёты и календарь

С первого взгляда видно, всё ли защищено; можно узнать, что происходило в любой день, и регулярно отправлять отчёты руководству или клиентам.

Панель

Первые карточки считают, что защищено: машины (копии файлов, образов и систем), ВМ, базы данных и общие папки NAS (появляются, когда есть хотя бы одна), — каждая с успешной копией. Требует внимания перечисляет, на что посмотреть: задания, последний запуск которых завершился ошибкой, задания, пропустившие расписание (нет успеха с предпоследнего запуска по расписанию — выходные и временные окна расписания учитываются), агенты, не подключавшиеся 15 минут, хранилища, заполненные на 90 % или которые заполнятся в течение 30 дней (см. Хранилища), и изменения, ожидающие подтверждения второго пользователя. Если список пуст, всё в порядке.

Остальные карточки показывают агентов в сети, задания копирования, хранилища, запуски в очереди и выполняемые, запуски, ошибки и предупреждения за последние 24 часа и подозрительных копий для проверки (возможный вымогатель, см. Защита от программ-вымогателей). Зелёный — всё хорошо, жёлтый — стоит взглянуть, красный — нужно действовать. Ниже — последняя активность.

Активность

Все запуски, сначала новые. Нажмите на запуск, чтобы увидеть подробности: что обработано, статистику, ошибки по файлам и — для копий — варианты восстановления. Выполняемые запуски обновляются автоматически. У запусков по расписанию значок часов.

Календарь

Календарь показывает по одному месяцу:

  • Прошедшие дни показывают, что действительно выполнялось — копирование и вторичные копии, — цветом по результату (зелёный, жёлтый, красный). Повторные запуски задания в один день объединяются, например 08:00 Офисные файлы ×6.
  • Будущие дни показывают, что запустят расписания (синим).
  • День с большим числом записей показывает четыре и +N ещё; нажмите, чтобы увидеть все, нажмите снова, чтобы свернуть.
  • Следующие 7 дней перечисляет все предстоящие запуски по порядку.

Отфильтруйте по агенту, чтобы увидеть план одной машины. Нажмите на запись, чтобы открыть задание. Задания вторичного копирования, выполняемые «после каждой копии», появляются в те дни, когда выполнялось их исходное задание.

Отчёты

Отчёты подводят итоги любого периода: сегодня, вчера, последние 7/30/90 дней, эта или прошлая неделя либо месяц, или произвольный диапазон дат — для всех агентов, одного агента или одного задания.

  • Число копий, доля успешных, успешные / с предупреждениями / неудачные запуски, прочитанные и отправленные данные, восстановления, тесты восстановления (и неудачные тесты), подозрительные копии.
  • График копий по дням.
  • По каждому заданию: запуски, доля успешных, последний результат, последняя исправная копия, защищённый объём, отправленные данные и результат последнего теста восстановления. Задание без исправной копии за период выделяется.
  • Все ошибки, предупреждения и подозрительные копии с их сообщениями.

Используйте CSV, чтобы открыть все запуски в Excel (с защитой от формул), Печать / PDF для документа или Отправить этот отчёт по почте. Те же данные доступны системам мониторинга через REST API (/api/v1/report).

Запланированные отчёты

В разделе Запланированные отчёты создайте отчёты, которые автоматически отправляются по почте по окончании периода:

  • Ежедневно — каждое утро, о предыдущем дне.
  • Еженедельно — каждый понедельник, о предыдущей неделе.
  • Ежемесячно — 1-го числа, о предыдущем месяце (идеально для клиентов или руководства).

Выберите час, охват (все агенты, один агент или одно задание) и получателей (пусто = получатели уведомлений). К письму прикладывается CSV со всеми запусками. Почта должна быть настроена в Настройки → Уведомления по почте. Создание и удаление запланированных отчётов требует роли Оператор копирования или Администратор.
