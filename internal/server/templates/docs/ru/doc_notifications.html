Уведомления: почта, Slack, Teams, вебхуки

Получайте письмо, когда копирование завершается с ошибкой, и ежедневную сводку каждое утро.

Настройка почты

В Настройки → Уведомления по почте:

ПолеПример
SMTP-сервер / портsmtp.office365.com / 587, smtp.gmail.com / 587, внутренний релей / 25
БезопасностьSTARTTLS (порт 587), TLS (порт 465) или нет (только внутренний релей)
Пользователь / парольПочтовый ящик, с которого идёт отправка; оставьте пустым для анонимного релея. Microsoft 365 и Gmail требуют пароль приложения.
Отправительbackup@example.com
ПолучателиОдин или несколько адресов через запятую.

Проверьте настройки кнопкой Отправить тестовое письмо.

Что отправляется

  • Ошибки (рекомендуется) — одно письмо на каждый неудачный запуск с причиной: копирование, вторичные копии, восстановления и неудачные тесты восстановления. С этой опцией вы также получаете оповещение SUSPICIOUS, когда копия похожа на работу вымогателя или массовое удаление.
  • Предупреждения — запуски, в которых часть файлов не удалось прочитать.
  • Успешные — каждый успешный запуск (обычно слишком много; лучше ежедневный отчёт).
  • Ежедневный отчёт — в выбранный час: запуски за последние 24 часа, проблемы и агенты не в сети. Тема начинается с OK, WARNINGS или ATTENTION, чтобы почтовые правила могли их сортировать.

Для еженедельных или ежемесячных сводок используйте отчёты по расписанию; они отправляются с теми же почтовыми настройками и имеют своих получателей. Темы начинаются с [BackupZit], чтобы почтовые правила могли их сортировать. Пароль SMTP хранится в зашифрованном виде.

Slack, Microsoft Teams и вебхуки

В Настройки → Чаты и вебхуки добавьте любое число каналов; каждый выбирает, получать ли ошибки, предупреждения и успешные запуски. Необычные копии (возможный вымогатель) считаются ошибками. Отправить тест сразу проверяет канал.

  • Slack: создайте для канала incoming webhook (настройки приложения Slack → Incoming Webhooks) и вставьте его URL (https://hooks.slack.com/services/…).
  • Microsoft Teams: в канале добавьте рабочий процесс Post to a channel when a webhook request is received и вставьте его URL. Сообщения приходят карточками с кнопкой, открывающей запуск в консоли.
  • Вебхук: любой URL, принимающий JSON POST — система заявок, мониторинг или средство автоматизации. С секретом подписи каждый запрос несёт X-BackupZit-Signature: sha256=<hex>, HMAC-SHA256 тела, чтобы получатель мог проверить, что запрос пришёл от вашей консоли.

JSON вебхука:

{"event": "run.finished", "run_id": 412, "kind": "vm-backup", "kind_title": "VM backup",
 "status": "failed", "suspicious": "", "job": "Proxmox VMs", "job_id": 7, "agent": "pve1",
 "message": "…", "errors": ["…"], "started_at": "2026-10-04T22:00:03+02:00",
 "finished_at": "2026-10-04T22:04:41+02:00", "url": "https://backup.example/runs/412"}

Сообщения отправляются один раз за запуск, даже когда почта выключена. Неработающий канал (неверный URL, сервис недоступен) записывается в журнал консоли и не задерживает остальные. URL вебхуков хранятся в зашифрованном виде.
