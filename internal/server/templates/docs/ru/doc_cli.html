Справочник по командной строке

Агент работает и самостоятельно из командной строки — для скриптов, для восстановления без консоли и в аварийных ситуациях. Запустите backupzit-agent без аргументов для обзора и backupzit-agent <command> -h для параметров команды.

Репозиторий и учётные данные

Каждая команда принимает --repo (или BACKUPZIT_REPO). Для секретов лучше использовать переменные окружения. Репозиторий агента — <место хранения>/<hostname>_<id>: см. столбец репозитория у запуска в разделе «Активность» или лист восстановления.

РасположениеУчётные данные
D:\Backups\pc1, /mnt/backup/pc1—
sftp://user@host:22/pathBACKUPZIT_SFTP_PASSWORD или --sftp-key file; --sftp-hostkey SHA256:… (BACKUPZIT_SFTP_HOSTKEY)
s3://endpoint/bucket/prefix (?tls=false для HTTP)BACKUPZIT_S3_ACCESS_KEY, BACKUPZIT_S3_SECRET_KEY, --s3-region; --s3-lock-days N пишет с Object Lock
smb://[domain;]user@host/share/pathBACKUPZIT_SMB_PASSWORD, --smb-domain
azure://account/container/path (?endpoint=URL для суверенных облаков, Azure Stack, Azurite)BACKUPZIT_AZURE_KEY или BACKUPZIT_AZURE_SAS
hardened://host:8500/pathBACKUPZIT_HARDENED_KEY, BACKUPZIT_HARDENED_FINGERPRINT
usb://LABEL/path (подстановочные знаки: usb://BZBACKUP*/BackupZit)— (используется подключённый диск с этой меткой тома)

Зашифрованным репозиториям нужен ключ восстановления в BACKUPZIT_PASSWORD (или --password).

Вид на момент времени: на S3 с Object Lock и в защищённом репозитории --as-of 2026-10-01T14:30 (или дата) показывает репозиторий таким, каким он был в тот момент, — только для чтения, чтобы восстановиться после удаления или перезаписи копий.

Файлы и папки

КомандаЧто делает
initСоздаёт новый репозиторий (зашифрованный, если указан пароль).
backup [--vss] [--exclude PATTERN]… [--tag TAG]… [--force] [--host NAME] PATH…Копирует файлы и папки. --vss читает из теневой копии тома (Windows, администратор); --force читает все файлы, даже неизменённые.
snapshotsВыводит снимки со временем, хостом, размером и путями.
ls SNAPSHOT|latest [PATH]Выводит файлы в снимке.
restore --target DIR [--include PATH]… [--verify] SNAPSHOT|latestВосстанавливает файлы в DIR (исходная структура папок воссоздаётся). --original вместо этого записывает их в исходное место, перезаписывая существующие файлы.
check [--read-data]Проверяет структуру репозитория; с --read-data каждый байт скачивается и проверяется.

Образы дисков (Windows)

КомандаЧто делает
disks [--json]Показывает диски и разделы с их номерами.
image-backup --disk N [--partitions 1,2] [--no-vss]
image-backup --all-disks		Копирует весь диск или выбранные разделы либо все внутренние диски в одном снимке.
image-restore --target-disk N --yes-erase-target [--keep-offline] [--source-disk N] SNAPSHOT|latestЗаписывает образ на диск; стирает диск. --keep-offline — если исходный диск в той же машине; --source-disk выбирает диск из копии всех дисков.
image-ls [--disk N] --partition N SNAPSHOT|latest [\path]Выводит файлы в разделе NTFS в образе (--disk: скопированный диск, для копий всех дисков).
image-extract [--disk N] --partition N --target DIR SNAPSHOT|latest \path…Копирует файлы и папки из раздела в образе.

Система Linux (bare metal, P2V)

КомандаЧто делает
system-backup [--exclude PATTERN]Копирует все локальные файловые системы и разметку дисков. См. Копирование системы Linux.
system-show SNAPSHOT|latestПоказывает разметку дисков в копии системы.
system-restore --target DEVICE [--new-hardware] [--rebuild-initramfs] --yes-erase-target SNAPSHOT|latestВоссоздаёт систему на пустом диске, логическом томе или в файле образа.

Windows: другое оборудование

КомандаЧто делает
prepare-hardware --disk N [--drivers DIR]Готовит восстановленный диск Windows к другому оборудованию (загрузочные драйверы, дополнительные драйверы, загрузочные файлы) — то же, что параметр восстановления, например чтобы повторить это с ISO восстановления.

VMware ESXi (любой агент как прокси; пароль в BACKUPZIT_VMWARE_PASSWORD)

КомандаЧто делает
vmware list --host H [--user root]Показывает ВМ хоста, режим лицензии, отпечатки сертификата и ключа SSH, а также хранилища данных.
vmware backup --host H [--vmid N,N]Копирует ВМ (по умолчанию все) из снимков; с Changed Block Tracking читаются только изменённые блоки.
vmware restore --host H --vmid N [--new] [--name X] [--datastore DS] [--overwrite] [--start] SNAPSHOT|latestВосстанавливает ВМ на месте (по умолчанию) или как новую ВМ с --new. --overwrite заменяет диски существующей ВМ; старые сохраняются под другим именем. См. VMware ESXi.
esxi-nfs-serveОтдаёт мгновенные ВМ хостам ESXi по NFS из /var/lib/backupzit/instant-esxi (Linux; запускается мгновенным восстановлением как unit systemd backupzit-esxi-nfs).

Закрепите хост с помощью --thumbprint SHA256:… и --ssh-host-key SHA256:… (их показывает vmware list).

Hyper-V (агент на хосте Hyper-V, от имени администратора)

КомандаЧто делает
hyperv listВыводит ВМ хоста с их номерами BackupZit и папки для восстановленных дисков.
hyperv backup [--vmid N,N]Копирует ВМ (по умолчанию все) из рабочих контрольных точек.
hyperv restore --vmid N [--new] [--name X] [--folder DIR] [--overwrite] [--start] SNAPSHOT|latestВосстанавливает ВМ на месте (по умолчанию) или как новую ВМ с --new. --overwrite заменяет диски существующей ВМ. См. Hyper-V.

pve show, pve ls и pve extract работают и с копиями Hyper-V.

Proxmox VE (агент на хосте Proxmox)

КомандаЧто делает
pve listВыводит ВМ и контейнеры кластера и хранилища, пригодные для восстановления.
pve backup [--vmid 100,200] [--exclude 300]Копирует гостей этого узла (по умолчанию всех) из снимков Proxmox.
pve show SNAPSHOT|latestПоказывает гостей и диски в копии ВМ.
pve ls --vmid N [--disk scsi0] [--volume ID] SNAPSHOT|latest [path]Выводит разделы и логические тома диска гостя или файлы в папке (NTFS, ext4, XFS, в том числе на LVM).
pve extract --vmid N --target DIR [--volume ID] SNAPSHOT|latest path...Копирует файлы и папки с диска гостя без восстановления ВМ.
pve restore --vmid N [--new-vmid -1|N] [--name X] [--storage S] [--overwrite] [--start] SNAPSHOT|latestВоссоздаёт гостя; --new-vmid -1 берёт следующий свободный ID, --overwrite заменяет существующего гостя с тем же ID. См. Proxmox VE.
pve instant --vmid N [--new-vmid N] [--name X] SNAPSHOT|latestМгновенное восстановление: запускает ВМ за секунды, пока её диски читаются из копии (новая ВМ, по умолчанию следующий свободный ID).
pve instant-finish --vmid N --storage SПереносит диски мгновенной ВМ в хранилище на ходу; после этого она больше не использует копию.
pve instant-discard --vmid NОстанавливает и удаляет мгновенную ВМ вместе с её изменениями.
nbd-serve --snapshot ID --vmid N --socket PATHОтдаёт диски ВМ из копии только для чтения по NBD через Unix-сокет (запускается мгновенным восстановлением как unit systemd).

Microsoft SQL Server (агент на машине с SQL Server)

КомандаЧто делает
sql list [--instance I]Выводит базы данных экземпляра с моделью восстановления и размером.
sql backup [--instance I] [--db a,b] [--system] [--log] [--copy-only]Полные копии (по умолчанию все пользовательские базы) или, с --log, копии журнала транзакций в репозиторий.
sql showВыводит копии SQL Server в репозитории с их диапазонами LSN.
sql restore --db NAME [--as NEW] [--replace] [--at TIME] SNAPSHOT|latestВосстанавливает базу из полной копии и последующих копий журнала, при желании на момент времени. См. SQL Server.

PostgreSQL и MySQL/MariaDB (агент на сервере баз данных)

КомандаЧто делает
pg list [--port P]Базы локального кластера и включено ли архивирование WAL.
pg backup [--port P] [--db a,b] [--pitr | --wal]Полная копия (pg_basebackup, pg_dump каждой базы; --pitr настраивает архивирование WAL) или, с --wal, архивированный WAL.
pg restore --db NAME|"(cluster)" [--as NEW] [--replace] [--at TIME | --latest] SNAPSHOT|latestВосстанавливает базу (из её дампа или на момент времени) или весь кластер как отдельный экземпляр.
mysql listБазы и включён ли двоичный журнал.
mysql backup [--db a,b] [--binlog]mysqldump каждой базы с её позицией в двоичном журнале или закрытые двоичные журналы.
mysql restore --db NAME [--as NEW] [--replace] [--at TIME | --latest] SNAPSHOT|latestЗагружает дамп и проигрывает двоичные журналы до момента времени. См. Базы данных.

Управляемый режим

КомандаЧто делает
enroll --code BZ1-… [--force]Подключает агента к консоли по коду регистрации со страницы «Агенты» (--force заменяет существующую регистрацию). Старая форма --server URL --token T --fingerprint F по-прежнему работает.
set-server https://address:8443Перенаправляет зарегистрированного агента на новый адрес консоли (тот же сертификат); затем перезапустите службу агента. См. Агенты.
statusПоказывает, что делает запущенный агент, и его задания копирования (значок в области уведомлений Windows показывает то же).
service install|uninstall|start|stop|status|runУправляет службой агента (это делают установщики).
recoveryРежим восстановления, автоматически запускается с ISO восстановления; в любой live-системе Linux: sudo backupzit-agent recovery --server URL --token CODE.
versionВыводит версию.

Примеры

set BACKUPZIT_PASSWORD=XXXX-XXXX-...
set BACKUPZIT_S3_ACCESS_KEY=...
set BACKUPZIT_S3_SECRET_KEY=...
backupzit-agent snapshots --repo s3://s3.wasabisys.com/company-backups/backupzit/pc1_1a2b3c4d
backupzit-agent restore --repo s3://s3.wasabisys.com/company-backups/backupzit/pc1_1a2b3c4d --target D:\Restore --include C:\Users\ana\Documents latest
backupzit-agent check --repo s3://... --read-data

backupzit-agent disks
backupzit-agent image-ls --repo usb://BZBACKUP1/BackupZit/pc1_1a2b3c4d --partition 3 latest \Users
backupzit-agent snapshots --repo hardened://vault:8500/backupzit/pc1_1a2b3c4d --as-of 2026-10-01T14:00

Защищённый репозиторий (backupzit-repo)

КомандаЧто делает
backupzit-repo serveЗапускает службу (это делает systemd).
backupzit-repo add-key NAMEСоздаёт ключ доступа (показывается один раз).
backupzit-repo keys / remove-key NAMEВывести / отозвать ключи доступа.
backupzit-repo fingerprintОтпечаток сертификата для консоли.
backupzit-repo statusСохранённые и скрытые (удалённые, но ещё хранящиеся) данные.
backupzit-repo undelete --since TIMEСнова делает видимыми файлы, удалённые начиная с TIME.

Конфигурация: /etc/backupzit-repo/repo.env — BACKUPZIT_REPO_LOCK_DAYS, BACKUPZIT_REPO_DATA, BACKUPZIT_REPO_LISTEN, BACKUPZIT_REPO_TLS_HOSTS.

Сервер управления (backupzit-server)

Параметр / окружениеЗначение
--db / BACKUPZIT_DBСтрока подключения PostgreSQL (обязательно).
--listen / BACKUPZIT_LISTENАдрес HTTPS, по умолчанию :8443.
--data-dir / BACKUPZIT_DATA_DIRСертификат, secrets.key, загрузки агентов (dist/).
--public-url / BACKUPZIT_PUBLIC_URLURL, который используют агенты и ссылки в письмах.
--tls-hosts / BACKUPZIT_TLS_HOSTSДополнительные имена/IP для самоподписанного сертификата.
BACKUPZIT_ADMIN_PASSWORDНачальный пароль администратора (только при первом запуске).
BACKUPZIT_SECRETS_KEYКлюч секретов (base64) вместо файла secrets.key.
--set-admin-password NEWСбрасывает пароль admin (снова включает его как локального администратора) и завершает работу.
--unblock-ip ADDRESS|allСнимает блокировку входа с адреса или со всех адресов (защита от перебора) и завершает работу.
--restore-console --repo R [--snapshot ID]Восстанавливает консоль из копии консоли и завершает работу (см. Установка сервера).
--dev-embedded-db, --dev-http ADDRТолько для пробы: частный PostgreSQL в каталоге данных, незашифрованный HTTP на localhost.
--versionВыводит версию.
