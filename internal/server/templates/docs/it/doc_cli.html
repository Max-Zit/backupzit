Riferimento della riga di comando

L'agente funziona anche da solo dalla riga di comando: per gli script, per ripristinare senza la console e per le emergenze. Eseguite backupzit-agent senza argomenti per una panoramica e backupzit-agent <command> -h per le opzioni di un comando.

Repository e credenziali

Ogni comando accetta --repo (o BACKUPZIT_REPO). Per i segreti preferite le variabili d'ambiente. Il repository di un agente è <posizione di archiviazione>/<hostname>_<id>: vedete la colonna repository di un'esecuzione in Attività, o il foglio di ripristino.

PosizioneCredenziali
D:\Backups\pc1, /mnt/backup/pc1—
sftp://user@host:22/pathBACKUPZIT_SFTP_PASSWORD o --sftp-key file; --sftp-hostkey SHA256:… (BACKUPZIT_SFTP_HOSTKEY)
s3://endpoint/bucket/prefix (?tls=false per HTTP)BACKUPZIT_S3_ACCESS_KEY, BACKUPZIT_S3_SECRET_KEY, --s3-region; --s3-lock-days N scrive con Object Lock
smb://[domain;]user@host/share/pathBACKUPZIT_SMB_PASSWORD, --smb-domain
azure://account/container/path (?endpoint=URL per cloud sovrani, Azure Stack, Azurite)BACKUPZIT_AZURE_KEY o BACKUPZIT_AZURE_SAS
hardened://host:8500/pathBACKUPZIT_HARDENED_KEY, BACKUPZIT_HARDENED_FINGERPRINT
usb://LABEL/path (caratteri jolly: usb://BZBACKUP*/BackupZit)— (viene usato il disco collegato con quell'etichetta di volume)

I repository cifrati richiedono la chiave di ripristino in BACKUPZIT_PASSWORD (o --password).

Vista a un momento preciso: su S3 con Object Lock e su un repository protetto, --as-of 2026-10-01T14:30 (o una data) mostra il repository com'era in quel momento, in sola lettura, per recuperare dopo che dei backup sono stati eliminati o sovrascritti.

File e cartelle

ComandoCosa fa
initCrea un nuovo repository (cifrato se viene fornita una password).
backup [--vss] [--exclude PATTERN]… [--tag TAG]… [--force] [--host NAME] PATH…Esegue il backup di file e cartelle. --vss legge da una copia shadow del volume (Windows, amministratore); --force legge tutti i file anche se non modificati.
snapshotsElenca gli snapshot con ora, host, dimensione e percorsi.
ls SNAPSHOT|latest [PATH]Elenca i file di uno snapshot.
restore --target DIR [--include PATH]… [--verify] SNAPSHOT|latestRipristina i file sotto DIR (viene ricreata la struttura di cartelle originale). --original li riscrive invece nella posizione originale, sovrascrivendo i file esistenti.
check [--read-data]Verifica la struttura del repository; con --read-data ogni byte viene scaricato e controllato.

Immagini disco (Windows)

ComandoCosa fa
disks [--json]Mostra dischi e partizioni con i loro numeri.
image-backup --disk N [--partitions 1,2] [--no-vss]
image-backup --all-disks		Esegue il backup di un disco intero o di partizioni scelte, oppure di tutti i dischi interni in un unico snapshot.
image-restore --target-disk N --yes-erase-target [--keep-offline] [--source-disk N] SNAPSHOT|latestScrive un'immagine su un disco; cancella il disco. --keep-offline quando il disco originale è nella stessa macchina; --source-disk sceglie il disco di un backup di tutti i dischi.
image-ls [--disk N] --partition N SNAPSHOT|latest [\path]Elenca i file di una partizione NTFS in un'immagine (--disk: il disco salvato, per i backup di tutti i dischi).
image-extract [--disk N] --partition N --target DIR SNAPSHOT|latest \path…Copia file e cartelle da una partizione in un'immagine.

Sistema Linux (bare metal, P2V)

ComandoCosa fa
system-backup [--exclude PATTERN]Esegue il backup di tutti i file system locali e del layout dei dischi. Vedete Backup del sistema Linux.
system-show SNAPSHOT|latestMostra il layout dei dischi di un backup di sistema.
system-restore --target DEVICE [--new-hardware] [--rebuild-initramfs] --yes-erase-target SNAPSHOT|latestRicrea il sistema su un disco vuoto, un volume logico o un file immagine.

Windows: hardware diverso

ComandoCosa fa
prepare-hardware --disk N [--drivers DIR]Prepara un disco Windows ripristinato per hardware diverso (driver di avvio, driver aggiuntivi, file di avvio), come l'opzione di ripristino, ad es. per ripeterla dalla ISO di ripristino.

VMware ESXi (qualsiasi agente come proxy; password in BACKUPZIT_VMWARE_PASSWORD)

ComandoCosa fa
vmware list --host H [--user root]Mostra le VM dell'host, la modalità di licenza, le impronte del certificato e della chiave SSH e i datastore.
vmware backup --host H [--vmid N,N]Esegue il backup delle VM (predefinito: tutte) da snapshot; con il Changed Block Tracking vengono letti solo i blocchi modificati.
vmware restore --host H --vmid N [--new] [--name X] [--datastore DS] [--overwrite] [--start] SNAPSHOT|latestRipristina una VM sul posto (predefinito) o come nuova VM con --new. --overwrite sostituisce i dischi di una VM esistente; i vecchi vengono conservati rinominati. Vedete VMware ESXi.
esxi-nfs-serveServe le VM istantanee degli host ESXi via NFS da /var/lib/backupzit/instant-esxi (Linux; avviato dal ripristino istantaneo come unità systemd backupzit-esxi-nfs).

Fissate l'host con --thumbprint SHA256:… e --ssh-host-key SHA256:… (mostrati da vmware list).

Hyper-V (agente sull'host Hyper-V, come amministratore)

ComandoCosa fa
hyperv listElenca le VM dell'host con i loro numeri BackupZit e le cartelle per i dischi ripristinati.
hyperv backup [--vmid N,N]Esegue il backup delle VM (predefinito: tutte) da checkpoint di produzione.
hyperv restore --vmid N [--new] [--name X] [--folder DIR] [--overwrite] [--start] SNAPSHOT|latestRipristina una VM sul posto (predefinito) o come nuova VM con --new. --overwrite sostituisce i dischi di una VM esistente. Vedete Hyper-V.

pve show, pve ls e pve extract funzionano anche con i backup Hyper-V.

Proxmox VE (agente sull'host Proxmox)

ComandoCosa fa
pve listElenca VM e container del cluster e lo storage utilizzabile per i ripristini.
pve backup [--vmid 100,200] [--exclude 300]Esegue il backup dei guest di questo nodo (predefinito: tutti) da snapshot Proxmox.
pve show SNAPSHOT|latestMostra i guest e i dischi di un backup di VM.
pve ls --vmid N [--disk scsi0] [--volume ID] SNAPSHOT|latest [path]Elenca partizioni e volumi logici di un disco guest, o i file di una cartella (NTFS, ext4, XFS, anche su LVM).
pve extract --vmid N --target DIR [--volume ID] SNAPSHOT|latest path...Copia file e cartelle da un disco guest senza ripristinare la VM.
pve restore --vmid N [--new-vmid -1|N] [--name X] [--storage S] [--overwrite] [--start] SNAPSHOT|latestRicrea un guest; --new-vmid -1 prende il prossimo ID libero, --overwrite sostituisce un guest esistente con lo stesso ID. Vedete Proxmox VE.
pve instant --vmid N [--new-vmid N] [--name X] SNAPSHOT|latestRipristino istantaneo: avvia una VM in pochi secondi mentre i suoi dischi vengono letti dal backup (nuova VM, per impostazione predefinita il prossimo ID libero).
pve instant-finish --vmid N --storage SSposta i dischi di una VM istantanea su uno storage mentre è in funzione; dopo non usa più il backup.
pve instant-discard --vmid NArresta ed elimina una VM istantanea con le sue modifiche.
nbd-serve --snapshot ID --vmid N --socket PATHServe i dischi di una VM di un backup in sola lettura via NBD su un socket Unix (avviato dal ripristino istantaneo come unità systemd).

Microsoft SQL Server (agente sulla macchina SQL Server)

ComandoCosa fa
sql list [--instance I]Elenca i database di un'istanza con modello di recupero e dimensione.
sql backup [--instance I] [--db a,b] [--system] [--log] [--copy-only]Backup completi (predefinito: tutti i database utente) o, con --log, backup del log delle transazioni nel repository.
sql showElenca i backup SQL Server del repository con i loro intervalli LSN.
sql restore --db NAME [--as NEW] [--replace] [--at TIME] SNAPSHOT|latestRipristina un database da un backup completo e dai backup del log successivi, eventualmente a un momento preciso. Vedete SQL Server.

PostgreSQL e MySQL/MariaDB (agente sul server di database)

ComandoCosa fa
pg list [--port P]Database del cluster locale e se l'archiviazione WAL è attiva.
pg backup [--port P] [--db a,b] [--pitr | --wal]Backup completo (pg_basebackup, pg_dump di ogni database; --pitr configura l'archiviazione WAL) o, con --wal, il WAL archiviato.
pg restore --db NAME|"(cluster)" [--as NEW] [--replace] [--at TIME | --latest] SNAPSHOT|latestRipristina un database (dal suo dump o a un momento preciso) o l'intero cluster come istanza separata.
mysql listDatabase e se il log binario è attivo.
mysql backup [--db a,b] [--binlog]mysqldump di ogni database con la sua posizione nel log binario, oppure i log binari chiusi.
mysql restore --db NAME [--as NEW] [--replace] [--at TIME | --latest] SNAPSHOT|latestCarica un dump e riapplica i log binari fino a un momento preciso. Vedete Database.

Modalità gestita

ComandoCosa fa
enroll --code BZ1-… [--force]Collega l'agente a una console con il codice di registrazione dalla pagina Agenti (--force sostituisce una registrazione esistente). La forma precedente --server URL --token T --fingerprint F funziona ancora.
set-server https://address:8443Indirizza un agente registrato verso un nuovo indirizzo della console (stesso certificato); poi riavviate il servizio dell'agente. Vedete Agenti.
statusMostra cosa sta facendo l'agente in esecuzione e i suoi job di backup (l'icona nell'area di notifica di Windows mostra lo stesso).
service install|uninstall|start|stop|status|runGestisce il servizio dell'agente (se ne occupano gli installer).
recoveryModalità di ripristino, avviata automaticamente dalle ISO di ripristino; su qualsiasi sistema Linux live: sudo backupzit-agent recovery --server URL --token CODE.
versionMostra la versione.

Esempi

set BACKUPZIT_PASSWORD=XXXX-XXXX-...
set BACKUPZIT_S3_ACCESS_KEY=...
set BACKUPZIT_S3_SECRET_KEY=...
backupzit-agent snapshots --repo s3://s3.wasabisys.com/company-backups/backupzit/pc1_1a2b3c4d
backupzit-agent restore --repo s3://s3.wasabisys.com/company-backups/backupzit/pc1_1a2b3c4d --target D:\Restore --include C:\Users\ana\Documents latest
backupzit-agent check --repo s3://... --read-data

backupzit-agent disks
backupzit-agent image-ls --repo usb://BZBACKUP1/BackupZit/pc1_1a2b3c4d --partition 3 latest \Users
backupzit-agent snapshots --repo hardened://vault:8500/backupzit/pc1_1a2b3c4d --as-of 2026-10-01T14:00

Repository protetto (backupzit-repo)

ComandoCosa fa
backupzit-repo serveEsegue il servizio (se ne occupa systemd).
backupzit-repo add-key NAMECrea una chiave di accesso (mostrata una volta).
backupzit-repo keys / remove-key NAMEElenca / revoca le chiavi di accesso.
backupzit-repo fingerprintImpronta del certificato per la console.
backupzit-repo statusDati salvati e nascosti (eliminati, ancora conservati).
backupzit-repo undelete --since TIMERende di nuovo visibili i file eliminati da TIME.

Configurazione: /etc/backupzit-repo/repo.env — BACKUPZIT_REPO_LOCK_DAYS, BACKUPZIT_REPO_DATA, BACKUPZIT_REPO_LISTEN, BACKUPZIT_REPO_TLS_HOSTS.
