Risoluzione dei problemi e FAQ

Un agente risulta offline

  • La macchina è accesa e il servizio è in esecuzione? Windows: Get-Service backupzit-agent; Linux: systemctl status backupzit-agent.
  • La macchina raggiunge la console? Test-NetConnection backup-server -Port 8443 oppure curl -k https://backup-server:8443/login.
  • Log dell'agente: C:\ProgramData\backupzit\agent.log, su Linux /etc/backupzit/agent.log o journalctl -u backupzit-agent. "fingerprint mismatch" significa che il certificato della console è cambiato — registra di nuovo l'agente.

Un backup non è riuscito

Apri l'esecuzione in Attività; il messaggio indica la causa. Cause comuni:

Il messaggio contieneSoluzione
host key mismatch / fingerprintLa chiave del server SFTP è cambiata o l'impronta è stata inserita male. Verifica con ssh-keygen -lf sul server.
permission denied / access deniedCredenziali dello storage o permessi della cartella. Prova l'accesso con un client SFTP/SMB.
no space left / quotaLo storage è pieno. Riduci la conservazione o aggiungi spazio; i backup scaduti liberano spazio dopo l'esecuzione successiva.
repository is lockedUn'altra operazione (ad es. una pulizia) è in corso sullo stesso repository; l'esecuzione riprova per 30 minuti. I lock obsoleti scadono automaticamente.
wrong password / recovery keyIl repository è stato creato con un'altra chiave — verifica che il job usi la destinazione di archiviazione corretta.
bucket has no Object Lock enabledÈ stata richiesta l'immutabilità su un bucket creato senza Object Lock. Crea un nuovo bucket con Object Lock.

Altri messaggi

SituazioneCosa fare
"no matching backup disk is connected"Collega uno dei dischi USB a rotazione (il messaggio indica l'etichetta richiesta e quali dischi etichettati sono collegati). Un ripristino richiede esattamente il disco indicato nell'esecuzione del backup.
"several backup disks are connected"Collega un solo disco a rotazione alla volta.
Test di ripristino non riuscitoApri l'esecuzione: il messaggio indica il file o blocco danneggiato o il motivo (ad es. backup eliminato sullo storage). Esegui backupzit-agent check --read-data sul repository, controlla lo storage e avvia un nuovo backup. Se sono stati eliminati backup su storage immutabile, vedi Protezione dal ransomware.
Backup contrassegnato come sospettoControlla la macchina per ransomware o una cancellazione di massa (ad es. una cartella sincronizzata svuotata). Se è tutto a posto (ad es. una migrazione pianificata), fai clic su Verificato — riprendi la conservazione nella pagina del job.
Let's Encrypt: "could not verify … is port 80 … reachable"La verifica HTTP richiede la porta 80 raggiungibile da Internet. Per le console interne usa la verifica DNS tramite Cloudflare.
Let's Encrypt: "no Cloudflare zone … is accessible with this token"Il token deve avere l'autorizzazione Zone → DNS → Edit per la zona che contiene il nome della console.
"HTTPS port 443: … permission denied" o "address already in use"Un altro programma usa la porta, oppure il servizio non può aprire porte sotto la 1024 (avvialo con CAP_NET_BIND_SERVICE, come fa il pacchetto). Scegli un'altra porta in Impostazioni → Certificato.
Aggiornamenti: "updates from the console need the Linux package of the console"La console non è stata installata dal pacchetto deb/rpm (ad esempio in modalità di valutazione). Aggiornala nello stesso modo in cui è stata installata.
Aggiornamenti: "the release is not signed with a BackupZit release key"La sorgente degli aggiornamenti non contiene una release ufficiale, oppure i file sono stati alterati lungo il percorso. Scaricali di nuovo dall'indirizzo ufficiale.
Aggiornamenti: stato rolled-backLa nuova versione non si è avviata, quindi sono stati ripristinati la precedente e il suo database. Il log dell'avvio non riuscito è nella pagina Aggiornamenti; invialo al supporto.
Sistema operativo: "no supported package manager"Gli aggiornamenti del sistema operativo sono supportati su Debian, Ubuntu (apt) e AlmaLinux, Rocky Linux, RHEL (dnf).
Backup della console: "the backup was made by a newer BackupZit"Prima del ripristino installa sulla nuova console la versione che ha creato il backup, o una più recente.
Backup della console: "console backups need network storage"Scegli una destinazione SFTP, S3, SMB, Azure o un repository protetto; un percorso locale di un agente non è raggiungibile dalla console.
"Troppi accessi non riusciti"Il tuo indirizzo è stato bloccato dopo password errate ripetute: per impostazione predefinita per 30 minuti, più a lungo per blocchi ripetuti. Un amministratore può rimuovere il blocco in Impostazioni → Accesso e sicurezza. Sul server, backupzit-server --unblock-ip all rimuove tutti i blocchi. Gli account non vengono mai bloccati in modo permanente.
Telefono perso per l'accesso a due fattoriUsa uno dei codici di ripristino; altrimenti un amministratore reimposta i due fattori nella tua pagina utente. L'ultimo amministratore può reimpostare la propria password sul server con backupzit-server --set-admin-password.
"your directory account is not in any BackupZit group"Aggiungi l'utente a uno dei gruppi associati in Impostazioni → LDAP / Active Directory, o associa più gruppi. Usa Test in quella pagina per vedere i gruppi trovati per un utente.
L'API restituisce 401 / 403401: token mancante, revocato, scaduto o con proprietario disattivato. 403: il ruolo del token è troppo basso per la richiesta.
Azure: AuthenticationFailed / AuthorizationPermissionMismatchChiave dell'account errata, oppure al token SAS manca l'autorizzazione di lettura, scrittura, eliminazione o elenco, o è scaduto.
Una VM ripristinata con Windows Server 2012 R2 / Windows 8.1 non si avvia su Hyper-V Gen 2 ("hash was denied (DBX)")Microsoft ha revocato il vecchio boot loader per Secure Boot. Disattiva Secure Boot per quella VM, oppure aggiorna il sistema prima del backup.

Macchine virtuali, sistemi Linux e nuovo hardware

SituazioneCosa fare
Proxmox: "the guest is running and one of its disks is on storage without snapshot support"I guest in esecuzione richiedono dischi LVM-thin, ZFS, Ceph RBD o qcow2. Sposta il disco (Disk Action → Move Storage) oppure esegui il backup del guest quando è arrestato.
Hyper-V: l'esecuzione indica "crash-consistent"Il guest non è riuscito a prepararsi per il checkpoint. Nei guest Windows verifica che i servizi di integrazione Hyper-V (Backup (volume shadow copy)) siano attivi nelle impostazioni della VM. Nei guest Linux installa hyperv-daemons (RHEL) o linux-cloud-tools / hyperv-daemons (Debian/Ubuntu).
VMware: "SSH off" o "SSH to …: connection refused"Attiva SSH sull'host ESXi: Host → Actions → Services → Enable Secure Shell (e impostalo per avviarsi con l'host). Servono per i ripristini e, con la licenza gratuita, per i backup.
VMware: "changed block tracking is off and can be enabled … only while the VM is off"Licenza ESXi gratuita: spegni la VM una volta, poi esegui il job; BackupZit attiva il Changed Block Tracking e i backup successivi leggono solo i blocchi modificati.
VMware: "copy the disk on the datastore (needs free space …)"Le VM accese vengono copiate brevemente sul loro datastore. Libera spazio lì (quanto ne usa il disco), oppure esegui il backup della VM spenta.
VMware: "… is a snapshot delta disk"La VM ha snapshot propri. Eliminali o consolidali nell'ESXi Host Client (Snapshots → Delete all).
VMware: "the ESXi certificate changed"L'host è stato reinstallato oppure un'altra macchina risponde al suo indirizzo. Se è previsto, rimuovi l'host in Agenti e aggiungilo di nuovo per fissare il nuovo certificato.
VMware: file *.replaced-DATE.vmdk accanto ai dischi della VMI vecchi dischi di una VM ripristinata sul posto. Eliminali nel browser del datastore quando la VM ripristinata funziona.
Hyper-V: file *.replaced-DATE accanto ai dischi della VMI vecchi dischi di una VM ripristinata sul posto. Eliminali quando la VM ripristinata funziona.
Ripristino istantaneo Proxmox: la VM non si avvia o si bloccaControlla il server dei dischi: systemctl status backupzit-instant-ID e journalctl -u backupzit-instant-ID sul nodo. Lo storage dei backup deve restare raggiungibile; se il repository non può essere letto, le letture del disco della VM si fermano.
Ripristino istantaneo Proxmox: "efidisk0 stays on storage backupzit-instant"QEMU non può spostare l'archivio delle variabili EFI mentre la VM è accesa. Spegni la VM ed esegui qm disk move ID efidisk0 STORAGE --delete 1; non dipende dal backup.
Proxmox: "runs on node X; install the BackupZit agent on X"Il guest è stato migrato. Installa l'agente su ogni nodo ed esegui il backup dei guest di ogni nodo con l'agente di quel nodo.
Backup o ripristini Proxmox lenti, SFTP "connection lost", "message authentication code incorrect" sul server di archiviazioneProblema noto delle schede di rete Intel e1000e sugli host Proxmox (log: "Detected Hardware Unit Hang", "Reset adapter unexpectedly"). Disattiva l'offloading: ethtool -K eno1 tso off gso off gro off e aggiungilo come riga post-up dell'interfaccia in /etc/network/interfaces.
Sfoglia file: "stored on a local path of the agent"La console può leggere solo backup su storage di rete. Usa backupzit-agent pve ls/extract o image-ls/image-extract sull'agente.
Ripristino del sistema Linux: "missing programs …"Installa i pacchetti indicati sulla macchina che esegue il ripristino, oppure avvia la ISO di ripristino Linux di BackupZit, che li contiene.
La macchina Linux ripristinata non ha reteLe impostazioni di rete erano legate al vecchio indirizzo MAC (netplan match: macaddress). Ripristina con Hardware diverso, oppure rimuovi le righe match in /etc/netplan/.
Il Windows ripristinato si ferma con INACCESSIBLE_BOOT_DEVICERipristina di nuovo con Ripristina su hardware diverso, oppure avvia la ISO di ripristino ed esegui backupzit-agent prepare-hardware --disk 0 [--drivers E:\Drivers].
Una copia ripristinata di una macchina compare come l'agente originaleI ripristini in una nuova VM Proxmox deregistrano automaticamente l'agente nella copia. Per altre copie, rimuovi agent.json nella copia e registrala come nuova macchina.
L'aggiornamento dell'agente non terminaConsulta il log del programma di installazione in C:\ProgramData\backupzit\updates o /var/tmp/backupzit-updates; gli agenti precedenti alla 0.21 vanno aggiornati una volta a mano.
Manca l'icona nell'area di notificaFai clic sulla freccia ^ accanto all'orologio e trascina l'icona di BackupZit sulla barra delle applicazioni, oppure avvia BackupZit Agent dal menu Start.

Un backup termina con "avviso"

Alcuni file non sono stati letti — di solito file bloccati da un'applicazione mentre VSS non è disponibile, o file per cui l'agente non ha autorizzazione. L'elenco è nella pagina dell'esecuzione. Tutto il resto è salvato.

I backup sono lenti

  • Il primo backup legge e carica tutto; i successivi leggono solo i file modificati e caricano solo i nuovi dati.
  • Controlla il percorso di rete verso lo storage (Wi-Fi, VPN, velocità di upload Internet per lo storage cloud).
  • Escludi cache, file temporanei e contenuti multimediali che non ti servono.

FAQ

Posso usare NFS?

Per eseguire il backup di una condivisione NFS (o SMB), crea un job NAS / condivisione file; un agente Linux monta l'export a ogni esecuzione. Per archiviare i backup su NFS, monta l'export sull'agente (Linux: /etc/fstab) e usa una destinazione Percorso locale / montato come /mnt/nfs-backup; per le macchine Windows una destinazione SMB è la scelta migliore.

Posso spostare i backup su un altro storage?

Copia la cartella del repository (o il prefisso del bucket) così com'è — è autonoma — e aggiungi una destinazione di archiviazione che punti alla nuova posizione con la stessa chiave di ripristino.

Eliminare un job elimina i backup?

No. I backup restano sullo storage e sono ripristinabili da Attività o dalla riga di comando.

Cosa succede se la console è inattiva?

Nessun nuovo backup pianificato parte finché non torna; le esecuzioni in coda proseguono dopo. I ripristini sono sempre possibili da riga di comando con la scheda di ripristino.

Quanto spazio serviranno i backup?

Per il primo backup, all'incirca la dimensione dei dati dopo la compressione, più le modifiche giornaliere per ogni giorno conservato. La pagina Report mostra quanto è stato caricato per job.
