Référence de la ligne de commande

L'agent fonctionne aussi seul en ligne de commande — pour les scripts, pour restaurer sans la console et pour les urgences. Lancez backupzit-agent sans argument pour un aperçu et backupzit-agent <command> -h pour les options d'une commande.

Dépôt et identifiants

Chaque commande accepte --repo (ou BACKUPZIT_REPO). Préférez les variables d'environnement pour les secrets. Le dépôt d'un agent est <emplacement de stockage>/<hostname>_<id> — voir la colonne dépôt d'une exécution dans Activité, ou la fiche de récupération.

EmplacementIdentifiants
D:\Backups\pc1, /mnt/backup/pc1—
sftp://user@host:22/pathBACKUPZIT_SFTP_PASSWORD ou --sftp-key file ; --sftp-hostkey SHA256:… (BACKUPZIT_SFTP_HOSTKEY)
s3://endpoint/bucket/prefix (?tls=false pour HTTP)BACKUPZIT_S3_ACCESS_KEY, BACKUPZIT_S3_SECRET_KEY, --s3-region ; --s3-lock-days N écrit avec Object Lock
smb://[domain;]user@host/share/pathBACKUPZIT_SMB_PASSWORD, --smb-domain
azure://account/container/path (?endpoint=URL pour les clouds souverains, Azure Stack, Azurite)BACKUPZIT_AZURE_KEY ou BACKUPZIT_AZURE_SAS
hardened://host:8500/pathBACKUPZIT_HARDENED_KEY, BACKUPZIT_HARDENED_FINGERPRINT
usb://LABEL/path (jokers : usb://BZBACKUP*/BackupZit)— (le disque connecté portant ce nom de volume est utilisé)

Les dépôts chiffrés nécessitent la clé de récupération dans BACKUPZIT_PASSWORD (ou --password).

Vue à un instant donné : sur S3 avec Object Lock et sur un dépôt renforcé, --as-of 2026-10-01T14:30 (ou une date) montre le dépôt tel qu'il était à ce moment — en lecture seule, pour récupérer après la suppression ou l'écrasement de sauvegardes.

Fichiers et dossiers

CommandeCe qu'elle fait
initCrée un nouveau dépôt (chiffré si un mot de passe est fourni).
backup [--vss] [--exclude PATTERN]… [--tag TAG]… [--force] [--host NAME] PATH…Sauvegarde des fichiers et dossiers. --vss lit depuis un cliché instantané de volume (Windows, administrateur) ; --force lit tous les fichiers même inchangés.
snapshotsListe les instantanés avec heure, hôte, taille et chemins.
ls SNAPSHOT|latest [PATH]Liste les fichiers d'un instantané.
restore --target DIR [--include PATH]… [--verify] SNAPSHOT|latestRestaure des fichiers sous DIR (l'arborescence d'origine est recréée). --original les réécrit plutôt à leur emplacement d'origine, en écrasant les fichiers existants.
check [--read-data]Vérifie la structure du dépôt ; avec --read-data, chaque octet est téléchargé et vérifié.

Images disque (Windows)

CommandeCe qu'elle fait
disks [--json]Affiche les disques et partitions avec leurs numéros.
image-backup --disk N [--partitions 1,2] [--no-vss]
image-backup --all-disks		Sauvegarde un disque entier ou des partitions choisies, ou tous les disques internes dans un seul instantané.
image-restore --target-disk N --yes-erase-target [--keep-offline] [--source-disk N] SNAPSHOT|latestÉcrit une image sur un disque ; efface le disque. --keep-offline lorsque le disque d'origine est dans la même machine ; --source-disk choisit le disque d'une sauvegarde de tous les disques.
image-ls [--disk N] --partition N SNAPSHOT|latest [\path]Liste les fichiers d'une partition NTFS imagée (--disk : le disque sauvegardé, pour les sauvegardes de tous les disques).
image-extract [--disk N] --partition N --target DIR SNAPSHOT|latest \path…Copie des fichiers et dossiers depuis une partition imagée.

Système Linux (bare metal, P2V)

CommandeCe qu'elle fait
system-backup [--exclude PATTERN]Sauvegarde tous les systèmes de fichiers locaux et la disposition des disques. Voir Sauvegarde du système Linux.
system-show SNAPSHOT|latestAffiche la disposition des disques d'une sauvegarde système.
system-restore --target DEVICE [--new-hardware] [--rebuild-initramfs] --yes-erase-target SNAPSHOT|latestRecrée le système sur un disque vide, un volume logique ou un fichier image.

Windows : matériel différent

CommandeCe qu'elle fait
prepare-hardware --disk N [--drivers DIR]Prépare un disque Windows restauré pour un matériel différent (pilotes d'amorçage, pilotes supplémentaires, fichiers d'amorçage) — comme l'option de restauration, par ex. pour la refaire depuis l'ISO de récupération.

VMware ESXi (n'importe quel agent comme proxy ; mot de passe dans BACKUPZIT_VMWARE_PASSWORD)

CommandeCe qu'elle fait
vmware list --host H [--user root]Affiche les VM de l'hôte, le mode de licence, les empreintes du certificat et de la clé SSH, et les datastores.
vmware backup --host H [--vmid N,N]Sauvegarde des VM (par défaut : toutes) à partir d'instantanés ; avec le suivi des blocs modifiés, seuls les blocs modifiés sont lus.
vmware restore --host H --vmid N [--new] [--name X] [--datastore DS] [--overwrite] [--start] SNAPSHOT|latestRestaure une VM sur place (par défaut) ou en tant que nouvelle VM avec --new. --overwrite remplace les disques d'une VM existante ; les anciens sont conservés renommés. Voir VMware ESXi.
esxi-nfs-serveSert les VM instantanées des hôtes ESXi via NFS depuis /var/lib/backupzit/instant-esxi (Linux ; lancé par la restauration instantanée comme unité systemd backupzit-esxi-nfs).

Épinglez l'hôte avec --thumbprint SHA256:… et --ssh-host-key SHA256:… (affichés par vmware list).

Hyper-V (agent sur l'hôte Hyper-V, en administrateur)

CommandeCe qu'elle fait
hyperv listListe les VM de l'hôte avec leurs numéros BackupZit, et les dossiers pour les disques restaurés.
hyperv backup [--vmid N,N]Sauvegarde des VM (par défaut : toutes) à partir de points de contrôle de production.
hyperv restore --vmid N [--new] [--name X] [--folder DIR] [--overwrite] [--start] SNAPSHOT|latestRestaure une VM sur place (par défaut) ou en tant que nouvelle VM avec --new. --overwrite remplace les disques d'une VM existante. Voir Hyper-V.

pve show, pve ls et pve extract fonctionnent aussi avec les sauvegardes Hyper-V.

Proxmox VE (agent sur l'hôte Proxmox)

CommandeCe qu'elle fait
pve listListe les VM et conteneurs du cluster et le stockage utilisable pour les restaurations.
pve backup [--vmid 100,200] [--exclude 300]Sauvegarde les invités de ce nœud (par défaut : tous) à partir d'instantanés Proxmox.
pve show SNAPSHOT|latestAffiche les invités et disques d'une sauvegarde de VM.
pve ls --vmid N [--disk scsi0] [--volume ID] SNAPSHOT|latest [path]Liste les partitions et volumes logiques d'un disque d'invité, ou les fichiers d'un dossier (NTFS, ext4, XFS, aussi sur LVM).
pve extract --vmid N --target DIR [--volume ID] SNAPSHOT|latest path...Copie des fichiers et dossiers depuis un disque d'invité sans restaurer la VM.
pve restore --vmid N [--new-vmid -1|N] [--name X] [--storage S] [--overwrite] [--start] SNAPSHOT|latestRecrée un invité ; --new-vmid -1 prend le prochain ID libre, --overwrite remplace un invité existant ayant le même ID. Voir Proxmox VE.
pve instant --vmid N [--new-vmid N] [--name X] SNAPSHOT|latestRestauration instantanée : démarre une VM en quelques secondes pendant que ses disques sont lus depuis la sauvegarde (nouvelle VM, prochain ID libre par défaut).
pve instant-finish --vmid N --storage SDéplace les disques d'une VM instantanée vers un stockage pendant qu'elle tourne ; ensuite elle n'utilise plus la sauvegarde.
pve instant-discard --vmid NArrête et supprime une VM instantanée avec ses modifications.
nbd-serve --snapshot ID --vmid N --socket PATHSert les disques d'une VM d'une sauvegarde en lecture seule via NBD sur un socket Unix (lancé par la restauration instantanée comme unité systemd).

Microsoft SQL Server (agent sur la machine SQL Server)

CommandeCe qu'elle fait
sql list [--instance I]Liste les bases d'une instance avec le mode de récupération et la taille.
sql backup [--instance I] [--db a,b] [--system] [--log] [--copy-only]Sauvegardes complètes (par défaut : toutes les bases utilisateur) ou, avec --log, sauvegardes des journaux de transactions dans le dépôt.
sql showListe les sauvegardes SQL Server du dépôt avec leurs plages LSN.
sql restore --db NAME [--as NEW] [--replace] [--at TIME] SNAPSHOT|latestRestaure une base depuis une sauvegarde complète et les sauvegardes de journaux qui la suivent, éventuellement à un instant précis. Voir SQL Server.

PostgreSQL et MySQL/MariaDB (agent sur le serveur de base de données)

CommandeCe qu'elle fait
pg list [--port P]Bases du cluster local et état de l'archivage WAL.
pg backup [--port P] [--db a,b] [--pitr | --wal]Sauvegarde complète (pg_basebackup, pg_dump de chaque base ; --pitr configure l'archivage WAL) ou, avec --wal, les WAL archivés.
pg restore --db NAME|"(cluster)" [--as NEW] [--replace] [--at TIME | --latest] SNAPSHOT|latestRestaure une base (depuis son dump ou à un instant précis) ou tout le cluster en tant qu'instance séparée.
mysql listBases et état du journal binaire.
mysql backup [--db a,b] [--binlog]mysqldump de chaque base avec sa position de journal binaire, ou les journaux binaires fermés.
mysql restore --db NAME [--as NEW] [--replace] [--at TIME | --latest] SNAPSHOT|latestCharge un dump et rejoue les journaux binaires jusqu'à un instant précis. Voir Bases de données.

Mode géré

CommandeCe qu'elle fait
enroll --code BZ1-… [--force]Connecte l'agent à une console avec le code d'inscription de la page Agents (--force remplace une inscription existante). L'ancienne forme --server URL --token T --fingerprint F fonctionne toujours.
set-server https://address:8443Pointe un agent inscrit vers une nouvelle adresse de la console (même certificat) ; redémarrez ensuite le service de l'agent. Voir Agents.
statusAffiche ce que fait l'agent en cours d'exécution et ses tâches de sauvegarde (l'icône de la zone de notification Windows affiche la même chose).
service install|uninstall|start|stop|status|runGère le service de l'agent (les installateurs le font).
recoveryMode récupération, lancé automatiquement par les ISO de récupération ; sur n'importe quel système Linux live : sudo backupzit-agent recovery --server URL --token CODE.
versionAffiche la version.

Exemples

set BACKUPZIT_PASSWORD=XXXX-XXXX-...
set BACKUPZIT_S3_ACCESS_KEY=...
set BACKUPZIT_S3_SECRET_KEY=...
backupzit-agent snapshots --repo s3://s3.wasabisys.com/company-backups/backupzit/pc1_1a2b3c4d
backupzit-agent restore --repo s3://s3.wasabisys.com/company-backups/backupzit/pc1_1a2b3c4d --target D:\Restore --include C:\Users\ana\Documents latest
backupzit-agent check --repo s3://... --read-data

backupzit-agent disks
backupzit-agent image-ls --repo usb://BZBACKUP1/BackupZit/pc1_1a2b3c4d --partition 3 latest \Users
backupzit-agent snapshots --repo hardened://vault:8500/backupzit/pc1_1a2b3c4d --as-of 2026-10-01T14:00

Dépôt renforcé (backupzit-repo)

CommandeCe qu'elle fait
backupzit-repo serveLance le service (systemd s'en charge).
backupzit-repo add-key NAMECrée une clé d'accès (affichée une fois).
backupzit-repo keys / remove-key NAMELister / révoquer les clés d'accès.
backupzit-repo fingerprintEmpreinte du certificat pour la console.
backupzit-repo statusDonnées stockées et masquées (supprimées, encore conservées).
backupzit-repo undelete --since TIMERend à nouveau visibles les fichiers supprimés depuis TIME.

Configuration : /etc/backupzit-repo/repo.env — BACKUPZIT_REPO_LOCK_DAYS, BACKUPZIT_REPO_DATA, BACKUPZIT_REPO_LISTEN, BACKUPZIT_REPO_TLS_HOSTS.

Option / environnementSignification
