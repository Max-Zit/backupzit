REST API

Integre o BackupZit a plataformas RMM, monitoramento (PRTG, Zabbix, Nagios, Uptime Kuma…) e seus próprios scripts.

Tokens

Crie um token em Minha conta → Tokens de API. Dê a ele a função mais baixa que seja suficiente — Visualizador para monitoramento, Operador de restauração para também iniciar backups e testes de restauração. O token é mostrado uma única vez; envie-o em cada requisição:

Authorization: Bearer bzt_...

Tokens podem expirar, ser revogados pelo dono ou por um administrador (Usuários) e param de funcionar quando o dono é desativado. Ações feitas com um token aparecem no log de auditoria com o nome do token.

Endpoints

Todas as respostas são JSON. URL base: https://<console>:8443.

Método e caminhoFunçãoRetorna
GET /api/v1/statusVisualizadorEstado geral: agentes online, falhas e avisos em 24 h, execuções ativas, backups suspeitos não revisados, "ok": true|false
GET /api/v1/agentsVisualizadorAgentes com sistema operacional, versão, estado online e último contato
GET /api/v1/jobs, GET /api/v1/jobs/{id}VisualizadorTarefas com agendamento, próxima execução e último resultado
POST /api/v1/jobs/{id}/runOperador de restauraçãoInicia a tarefa agora: {"run_id": 123} (202), ou 409 se já houver uma execução ativa
POST /api/v1/jobs/{id}/testOperador de restauraçãoInicia um teste de restauração do backup mais recente da tarefa
GET /api/v1/runs?job=&agent=&status=&limit=VisualizadorExecuções recentes, da mais nova (padrão 100, máximo 1000)
GET /api/v1/runs/{id}VisualizadorUma execução com mensagem, erros e estatísticas
GET /api/v1/report?period=&from=&to=&agent=&job=VisualizadorO relatório de um período: totais, taxa de sucesso e detalhes por tarefa
GET /api/v1/targetsVisualizadorDestinos de armazenamento (sem credenciais)

Períodos: today, yesterday, last7, last30, last90, thisweek, lastweek, thismonth, lastmonth, ou custom com from=2026-09-01&to=2026-09-30.

Erros retornam {"error": "..."} com 400 (requisição inválida), 401 (token ausente, inválido ou expirado), 403 (função insuficiente), 404 ou 409.

Exemplos

curl

curl -sk -H "Authorization: Bearer $BZ_TOKEN" https://backup.example.local:8443/api/v1/status
curl -sk -X POST -H "Authorization: Bearer $BZ_TOKEN" https://backup.example.local:8443/api/v1/jobs/7/run

PowerShell

$h = @{ Authorization = "Bearer $env:BZ_TOKEN" }
$s = Invoke-RestMethod -Uri https://backup.example.local:8443/api/v1/status -Headers $h -SkipCertificateCheck
if (-not $s.ok) { Write-Warning "BackupZit needs attention: $($s.failed_24h) failed backups" }

Use -k / -SkipCertificateCheck somente com o certificado autoassinado do console em uma rede confiável, ou instale o certificado do console no host de monitoramento.

Verificação de monitoramento

Consulte /api/v1/status a cada poucos minutos e alerte quando ok for false. Para verificar cada tarefa use /api/v1/jobs e alerte quando last_status for failed ou last_finished for mais antigo que o esperado.
