Referência da linha de comandos

O agente também funciona sozinho na linha de comandos: para scripts, para restaurar sem a console e para emergências. Execute backupzit-agent sem argumentos para uma visão geral e backupzit-agent <command> -h para as opções de um comando.

Repositório e credenciais

Todos os comandos aceitam --repo (ou BACKUPZIT_REPO). Para segredos, prefira variáveis de ambiente. O repositório de um agente é <local de armazenamento>/<hostname>_<id>: veja a coluna de repositório de uma execução em Atividade, ou a ficha de recuperação.

LocalCredenciais
D:\Backups\pc1, /mnt/backup/pc1—
sftp://user@host:22/pathBACKUPZIT_SFTP_PASSWORD ou --sftp-key file; --sftp-hostkey SHA256:… (BACKUPZIT_SFTP_HOSTKEY)
s3://endpoint/bucket/prefix (?tls=false para HTTP)BACKUPZIT_S3_ACCESS_KEY, BACKUPZIT_S3_SECRET_KEY, --s3-region; --s3-lock-days N grava com Object Lock
smb://[domain;]user@host/share/pathBACKUPZIT_SMB_PASSWORD, --smb-domain
azure://account/container/path (?endpoint=URL para nuvens soberanas, Azure Stack, Azurite)BACKUPZIT_AZURE_KEY ou BACKUPZIT_AZURE_SAS
hardened://host:8500/pathBACKUPZIT_HARDENED_KEY, BACKUPZIT_HARDENED_FINGERPRINT
usb://LABEL/path (curingas: usb://BZBACKUP*/BackupZit)— (é usado o disco conectado com esse rótulo de volume)

Repositórios criptografados precisam da chave de recuperação em BACKUPZIT_PASSWORD (ou --password).

Vista num momento: no S3 com Object Lock e num repositório protegido, --as-of 2026-10-01T14:30 (ou uma data) mostra o repositório como estava nesse momento, somente leitura, para recuperar depois de backups terem sido excluídos ou sobrescritos.

Arquivos e pastas

ComandoO que faz
initCria um novo repositório (criptografado se for dada uma senha).
backup [--vss] [--exclude PATTERN]… [--tag TAG]… [--force] [--host NAME] PATH…Faz backup de arquivos e pastas. --vss lê de uma cópia de sombra do volume (Windows, administrador); --force lê todos os arquivos, mesmo os inalterados.
snapshotsLista os snapshots com hora, host, tamanho e caminhos.
ls SNAPSHOT|latest [PATH]Lista os arquivos de um snapshot.
restore --target DIR [--include PATH]… [--verify] SNAPSHOT|latestRestaura arquivos em DIR (a estrutura de pastas original é recriada). --original grava-os no local original, sobrescrevendo os arquivos existentes.
check [--read-data]Verifica a estrutura do repositório; com --read-data cada byte é baixado e verificado.

Imagens de disco (Windows)

ComandoO que faz
disks [--json]Mostra discos e partições com os seus números.
image-backup --disk N [--partitions 1,2] [--no-vss]
image-backup --all-disks		Faz backup de um disco inteiro ou de partições escolhidas, ou de todos os discos internos num único snapshot.
image-restore --target-disk N --yes-erase-target [--keep-offline] [--source-disk N] SNAPSHOT|latestGrava uma imagem num disco; apaga o disco. --keep-offline quando o disco original está na mesma máquina; --source-disk escolhe o disco de um backup de todos os discos.
image-ls [--disk N] --partition N SNAPSHOT|latest [\path]Lista os arquivos de uma partição NTFS numa imagem (--disk: o disco salvo, em backups de todos os discos).
image-extract [--disk N] --partition N --target DIR SNAPSHOT|latest \path…Copia arquivos e pastas de uma partição numa imagem.

Sistema Linux (bare metal, P2V)

ComandoO que faz
system-backup [--exclude PATTERN]Faz backup de todos os sistemas de arquivos locais e do layout dos discos. Veja Backup do sistema Linux.
system-show SNAPSHOT|latestMostra o layout dos discos de um backup de sistema.
system-restore --target DEVICE [--new-hardware] [--rebuild-initramfs] --yes-erase-target SNAPSHOT|latestRecria o sistema num disco vazio, num volume lógico ou num arquivo de imagem.

Windows: hardware diferente

ComandoO que faz
prepare-hardware --disk N [--drivers DIR]Prepara um disco Windows restaurado para hardware diferente (drivers de arranque, drivers adicionais, arquivos de arranque), tal como a opção de restauração, p. ex. para repetir a partir da ISO de recuperação.

VMware ESXi (qualquer agente como proxy; senha em BACKUPZIT_VMWARE_PASSWORD)

ComandoO que faz
vmware list --host H [--user root]Mostra as VMs do host, o modo de licença, as impressões digitais do certificado e da chave SSH, e os datastores.
vmware backup --host H [--vmid N,N]Faz backup de VMs (padrão: todas) a partir de snapshots; com o Changed Block Tracking só são lidos os blocos alterados.
vmware restore --host H --vmid N [--new] [--name X] [--datastore DS] [--overwrite] [--start] SNAPSHOT|latestRestaura uma VM no local (padrão) ou como nova VM com --new. --overwrite substitui os discos de uma VM existente; os antigos são mantidos renomeados. Veja VMware ESXi.
esxi-nfs-serveServe as VMs instantâneas dos hosts ESXi por NFS a partir de /var/lib/backupzit/instant-esxi (Linux; iniciado pela recuperação instantânea como unidade systemd backupzit-esxi-nfs).

Fixe o host com --thumbprint SHA256:… e --ssh-host-key SHA256:… (mostrados por vmware list).

Hyper-V (agente no host Hyper-V, como administrador)

ComandoO que faz
hyperv listLista as VMs do host com os seus números BackupZit, e as pastas para discos restaurados.
hyperv backup [--vmid N,N]Faz backup de VMs (padrão: todas) a partir de pontos de verificação de produção.
hyperv restore --vmid N [--new] [--name X] [--folder DIR] [--overwrite] [--start] SNAPSHOT|latestRestaura uma VM no local (padrão) ou como nova VM com --new. --overwrite substitui os discos de uma VM existente. Veja Hyper-V.

pve show, pve ls e pve extract também funcionam com backups Hyper-V.

Proxmox VE (agente no host Proxmox)

ComandoO que faz
pve listLista as VMs e contêineres do cluster e o armazenamento utilizável para restaurações.
pve backup [--vmid 100,200] [--exclude 300]Faz backup dos convidados deste nó (padrão: todos) a partir de snapshots do Proxmox.
pve show SNAPSHOT|latestMostra os convidados e discos de um backup de VM.
pve ls --vmid N [--disk scsi0] [--volume ID] SNAPSHOT|latest [path]Lista as partições e volumes lógicos de um disco de convidado, ou os arquivos de uma pasta (NTFS, ext4, XFS, também sobre LVM).
pve extract --vmid N --target DIR [--volume ID] SNAPSHOT|latest path...Copia arquivos e pastas de um disco de convidado sem restaurar a VM.
pve restore --vmid N [--new-vmid -1|N] [--name X] [--storage S] [--overwrite] [--start] SNAPSHOT|latestRecria um convidado; --new-vmid -1 usa o próximo ID livre, --overwrite substitui um convidado existente com o mesmo ID. Veja Proxmox VE.
pve instant --vmid N [--new-vmid N] [--name X] SNAPSHOT|latestRecuperação instantânea: inicia uma VM em segundos enquanto os seus discos são lidos do backup (nova VM, próximo ID livre por padrão).
pve instant-finish --vmid N --storage SMove os discos de uma VM instantânea para um armazenamento enquanto ela funciona; depois deixa de usar o backup.
pve instant-discard --vmid NPara e exclui uma VM instantânea com as suas alterações.
nbd-serve --snapshot ID --vmid N --socket PATHServe os discos de uma VM de um backup, somente leitura, por NBD num socket Unix (iniciado pela recuperação instantânea como unidade systemd).

Microsoft SQL Server (agente na máquina do SQL Server)

ComandoO que faz
sql list [--instance I]Lista os bancos de dados de uma instância com o modelo de recuperação e o tamanho.
sql backup [--instance I] [--db a,b] [--system] [--log] [--copy-only]Backups completos (padrão: todos os bancos de usuário) ou, com --log, backups de log de transações para o repositório.
sql showLista os backups do SQL Server no repositório com os seus intervalos de LSN.
sql restore --db NAME [--as NEW] [--replace] [--at TIME] SNAPSHOT|latestRestaura um banco de dados a partir de um backup completo e dos backups de log posteriores, opcionalmente para um momento. Veja SQL Server.

PostgreSQL e MySQL/MariaDB (agente no servidor de banco de dados)

ComandoO que faz
pg list [--port P]Bancos do cluster local e se o arquivamento de WAL está ativo.
pg backup [--port P] [--db a,b] [--pitr | --wal]Backup completo (pg_basebackup, pg_dump de cada banco; --pitr configura o arquivamento de WAL) ou, com --wal, o WAL arquivado.
pg restore --db NAME|"(cluster)" [--as NEW] [--replace] [--at TIME | --latest] SNAPSHOT|latestRestaura um banco (do seu dump ou para um momento) ou o cluster inteiro como instância separada.
mysql listBancos e se o log binário está ativo.
mysql backup [--db a,b] [--binlog]mysqldump de cada banco com a sua posição no log binário, ou os logs binários fechados.
mysql restore --db NAME [--as NEW] [--replace] [--at TIME | --latest] SNAPSHOT|latestCarrega um dump e reaplica os logs binários até um momento. Veja Bancos de dados.

Modo gerenciado

ComandoO que faz
enroll --code BZ1-… [--force]Liga o agente a uma console com o código de registro da página Agentes (--force substitui um registro existente). A forma antiga --server URL --token T --fingerprint F continua a funcionar.
set-server https://address:8443Aponta um agente registrado para um novo endereço da console (mesmo certificado); depois reinicie o serviço do agente. Veja Agentes.
statusMostra o que o agente em execução está fazendo e os seus trabalhos de backup (o ícone da bandeja do Windows mostra o mesmo).
service install|uninstall|start|stop|status|runGerencia o serviço do agente (os instaladores fazem isso).
recoveryModo de recuperação, iniciado automaticamente pelas ISOs de recuperação; em qualquer sistema Linux live: sudo backupzit-agent recovery --server URL --token CODE.
versionMostra a versão.

Exemplos

set BACKUPZIT_PASSWORD=XXXX-XXXX-...
set BACKUPZIT_S3_ACCESS_KEY=...
set BACKUPZIT_S3_SECRET_KEY=...
backupzit-agent snapshots --repo s3://s3.wasabisys.com/company-backups/backupzit/pc1_1a2b3c4d
backupzit-agent restore --repo s3://s3.wasabisys.com/company-backups/backupzit/pc1_1a2b3c4d --target D:\Restore --include C:\Users\ana\Documents latest
backupzit-agent check --repo s3://... --read-data

backupzit-agent disks
backupzit-agent image-ls --repo usb://BZBACKUP1/BackupZit/pc1_1a2b3c4d --partition 3 latest \Users
backupzit-agent snapshots --repo hardened://vault:8500/backupzit/pc1_1a2b3c4d --as-of 2026-10-01T14:00

Repositório protegido (backupzit-repo)

ComandoO que faz
backupzit-repo serveExecuta o serviço (o systemd faz isso).
backupzit-repo add-key NAMECria uma chave de acesso (mostrada uma vez).
backupzit-repo keys / remove-key NAMEListar / revogar chaves de acesso.
backupzit-repo fingerprintImpressão digital do certificado para a console.
backupzit-repo statusDados guardados e ocultos (excluídos, ainda retidos).
backupzit-repo undelete --since TIMETorna novamente visíveis os arquivos excluídos desde TIME.

Configuração: /etc/backupzit-repo/repo.env — BACKUPZIT_REPO_LOCK_DAYS, BACKUPZIT_REPO_DATA, BACKUPZIT_REPO_LISTEN, BACKUPZIT_REPO_TLS_HOSTS.
