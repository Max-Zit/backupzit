Referencia de la línea de comandos

El agente también funciona por sí solo desde la línea de comandos: para scripts, para restaurar sin la consola y para emergencias. Ejecute backupzit-agent sin argumentos para ver un resumen y backupzit-agent <command> -h para las opciones de un comando.

Repositorio y credenciales

Todos los comandos aceptan --repo (o BACKUPZIT_REPO). Para los secretos, mejor use variables de entorno. El repositorio de un agente es <ubicación de almacenamiento>/<hostname>_<id>: vea la columna de repositorio de una ejecución en Actividad, o la hoja de recuperación.

UbicaciónCredenciales
D:\Backups\pc1, /mnt/backup/pc1—
sftp://user@host:22/pathBACKUPZIT_SFTP_PASSWORD o --sftp-key file; --sftp-hostkey SHA256:… (BACKUPZIT_SFTP_HOSTKEY)
s3://endpoint/bucket/prefix (?tls=false para HTTP)BACKUPZIT_S3_ACCESS_KEY, BACKUPZIT_S3_SECRET_KEY, --s3-region; --s3-lock-days N escribe con Object Lock
smb://[domain;]user@host/share/pathBACKUPZIT_SMB_PASSWORD, --smb-domain
azure://account/container/path (?endpoint=URL para nubes soberanas, Azure Stack, Azurite)BACKUPZIT_AZURE_KEY o BACKUPZIT_AZURE_SAS
hardened://host:8500/pathBACKUPZIT_HARDENED_KEY, BACKUPZIT_HARDENED_FINGERPRINT
usb://LABEL/path (comodines: usb://BZBACKUP*/BackupZit)— (se usa el disco conectado con esa etiqueta de volumen)

Los repositorios cifrados necesitan la clave de recuperación en BACKUPZIT_PASSWORD (o --password).

Vista en un momento concreto: en S3 con Object Lock y en un repositorio reforzado, --as-of 2026-10-01T14:30 (o una fecha) muestra el repositorio tal como estaba en ese momento, en solo lectura, para recuperarse después de que se borraran o sobrescribieran copias.

Archivos y carpetas

ComandoQué hace
initCrea un repositorio nuevo (cifrado si se indica una contraseña).
backup [--vss] [--exclude PATTERN]… [--tag TAG]… [--force] [--host NAME] PATH…Copia archivos y carpetas. --vss lee de una instantánea de volumen (Windows, administrador); --force lee todos los archivos aunque no hayan cambiado.
snapshotsMuestra las instantáneas con hora, host, tamaño y rutas.
ls SNAPSHOT|latest [PATH]Muestra los archivos de una instantánea.
restore --target DIR [--include PATH]… [--verify] SNAPSHOT|latestRestaura archivos bajo DIR (se recrea la estructura de carpetas original). --original los escribe en cambio en su ubicación original, sobrescribiendo los archivos existentes.
check [--read-data]Verifica la estructura del repositorio; con --read-data se descarga y comprueba cada byte.

Imágenes de disco (Windows)

ComandoQué hace
disks [--json]Muestra los discos y particiones con sus números.
image-backup --disk N [--partitions 1,2] [--no-vss]
image-backup --all-disks		Copia un disco completo o particiones elegidas, o todos los discos internos en una sola instantánea.
image-restore --target-disk N --yes-erase-target [--keep-offline] [--source-disk N] SNAPSHOT|latestEscribe una imagen en un disco; borra el disco. --keep-offline cuando el disco original está en la misma máquina; --source-disk elige el disco de una copia de todos los discos.
image-ls [--disk N] --partition N SNAPSHOT|latest [\path]Muestra los archivos de una partición NTFS de una imagen (--disk: el disco copiado, en copias de todos los discos).
image-extract [--disk N] --partition N --target DIR SNAPSHOT|latest \path…Copia archivos y carpetas desde una partición de una imagen.

Sistema Linux (bare metal, P2V)

ComandoQué hace
system-backup [--exclude PATTERN]Copia todos los sistemas de archivos locales y la disposición de los discos. Consulte Copia del sistema Linux.
system-show SNAPSHOT|latestMuestra la disposición de los discos de una copia del sistema.
system-restore --target DEVICE [--new-hardware] [--rebuild-initramfs] --yes-erase-target SNAPSHOT|latestRecrea el sistema en un disco vacío, un volumen lógico o un archivo de imagen.

Windows: hardware distinto

ComandoQué hace
prepare-hardware --disk N [--drivers DIR]Prepara un disco de Windows restaurado para hardware distinto (controladores de arranque, controladores adicionales, archivos de arranque), igual que la opción de restauración, p. ej. para repetirlo desde la ISO de recuperación.

VMware ESXi (cualquier agente como proxy; contraseña en BACKUPZIT_VMWARE_PASSWORD)

ComandoQué hace
vmware list --host H [--user root]Muestra las VM del host, el modo de licencia, las huellas del certificado y de la clave SSH, y los datastores.
vmware backup --host H [--vmid N,N]Copia VM (por defecto: todas) a partir de instantáneas; con el seguimiento de bloques cambiados solo se leen los bloques cambiados.
vmware restore --host H --vmid N [--new] [--name X] [--datastore DS] [--overwrite] [--start] SNAPSHOT|latestRestaura una VM en el sitio (por defecto) o como VM nueva con --new. --overwrite sustituye los discos de una VM existente; los antiguos se conservan renombrados. Consulte VMware ESXi.
esxi-nfs-serveSirve las VM instantáneas de los hosts ESXi por NFS desde /var/lib/backupzit/instant-esxi (Linux; la recuperación instantánea lo inicia como unidad systemd backupzit-esxi-nfs).

Fije el host con --thumbprint SHA256:… y --ssh-host-key SHA256:… (los muestra vmware list).

Hyper-V (agente en el host Hyper-V, como administrador)

ComandoQué hace
hyperv listMuestra las VM del host con sus números de BackupZit, y las carpetas para los discos restaurados.
hyperv backup [--vmid N,N]Copia VM (por defecto: todas) a partir de puntos de control de producción.
hyperv restore --vmid N [--new] [--name X] [--folder DIR] [--overwrite] [--start] SNAPSHOT|latestRestaura una VM en el sitio (por defecto) o como VM nueva con --new. --overwrite sustituye los discos de una VM existente. Consulte Hyper-V.

pve show, pve ls y pve extract también funcionan con copias de Hyper-V.

Proxmox VE (agente en el host Proxmox)

ComandoQué hace
pve listMuestra las VM y contenedores del clúster y el almacenamiento utilizable para restauraciones.
pve backup [--vmid 100,200] [--exclude 300]Copia los invitados de este nodo (por defecto: todos) a partir de instantáneas de Proxmox.
pve show SNAPSHOT|latestMuestra los invitados y discos de una copia de VM.
pve ls --vmid N [--disk scsi0] [--volume ID] SNAPSHOT|latest [path]Muestra las particiones y volúmenes lógicos de un disco de invitado, o los archivos de una carpeta (NTFS, ext4, XFS, también sobre LVM).
pve extract --vmid N --target DIR [--volume ID] SNAPSHOT|latest path...Copia archivos y carpetas de un disco de invitado sin restaurar la VM.
pve restore --vmid N [--new-vmid -1|N] [--name X] [--storage S] [--overwrite] [--start] SNAPSHOT|latestRecrea un invitado; --new-vmid -1 toma el siguiente ID libre, --overwrite sustituye un invitado existente con el mismo ID. Consulte Proxmox VE.
pve instant --vmid N [--new-vmid N] [--name X] SNAPSHOT|latestRecuperación instantánea: inicia una VM en segundos mientras sus discos se leen de la copia (VM nueva, siguiente ID libre por defecto).
pve instant-finish --vmid N --storage SMueve los discos de una VM instantánea a un almacenamiento mientras funciona; después ya no usa la copia.
pve instant-discard --vmid NDetiene y elimina una VM instantánea con sus cambios.
nbd-serve --snapshot ID --vmid N --socket PATHSirve los discos de una VM de una copia en solo lectura por NBD en un socket Unix (la recuperación instantánea lo inicia como unidad systemd).

Microsoft SQL Server (agente en la máquina de SQL Server)

ComandoQué hace
sql list [--instance I]Muestra las bases de una instancia con el modelo de recuperación y el tamaño.
sql backup [--instance I] [--db a,b] [--system] [--log] [--copy-only]Copias completas (por defecto: todas las bases de usuario) o, con --log, copias de registros de transacciones en el repositorio.
sql showMuestra las copias de SQL Server del repositorio con sus rangos de LSN.
sql restore --db NAME [--as NEW] [--replace] [--at TIME] SNAPSHOT|latestRestaura una base desde una copia completa y las copias de registros posteriores, opcionalmente a un momento concreto. Consulte SQL Server.

PostgreSQL y MySQL/MariaDB (agente en el servidor de base de datos)

ComandoQué hace
pg list [--port P]Bases del clúster local y si el archivado de WAL está activo.
pg backup [--port P] [--db a,b] [--pitr | --wal]Copia completa (pg_basebackup, pg_dump de cada base; --pitr configura el archivado de WAL) o, con --wal, el WAL archivado.
pg restore --db NAME|"(cluster)" [--as NEW] [--replace] [--at TIME | --latest] SNAPSHOT|latestRestaura una base (desde su volcado o a un momento concreto) o el clúster completo como instancia aparte.
mysql listBases y si el registro binario está activo.
mysql backup [--db a,b] [--binlog]mysqldump de cada base con su posición del registro binario, o los registros binarios cerrados.
mysql restore --db NAME [--as NEW] [--replace] [--at TIME | --latest] SNAPSHOT|latestCarga un volcado y reproduce los registros binarios hasta un momento concreto. Consulte Bases de datos.

Modo gestionado

ComandoQué hace
enroll --code BZ1-… [--force]Conecta el agente a una consola con el código de registro de la página Agentes (--force sustituye un registro existente). La forma antigua --server URL --token T --fingerprint F sigue funcionando.
set-server https://address:8443Apunta un agente registrado a una nueva dirección de la consola (mismo certificado); después reinicie el servicio del agente. Consulte Agentes.
statusMuestra qué está haciendo el agente en ejecución y sus trabajos de copia (el icono de la bandeja de Windows muestra lo mismo).
service install|uninstall|start|stop|status|runGestiona el servicio del agente (lo hacen los instaladores).
recoveryModo de recuperación, iniciado automáticamente por las ISO de recuperación; en cualquier sistema Linux en vivo: sudo backupzit-agent recovery --server URL --token CODE.
versionMuestra la versión.

Ejemplos

set BACKUPZIT_PASSWORD=XXXX-XXXX-...
set BACKUPZIT_S3_ACCESS_KEY=...
set BACKUPZIT_S3_SECRET_KEY=...
backupzit-agent snapshots --repo s3://s3.wasabisys.com/company-backups/backupzit/pc1_1a2b3c4d
backupzit-agent restore --repo s3://s3.wasabisys.com/company-backups/backupzit/pc1_1a2b3c4d --target D:\Restore --include C:\Users\ana\Documents latest
backupzit-agent check --repo s3://... --read-data

backupzit-agent disks
backupzit-agent image-ls --repo usb://BZBACKUP1/BackupZit/pc1_1a2b3c4d --partition 3 latest \Users
backupzit-agent snapshots --repo hardened://vault:8500/backupzit/pc1_1a2b3c4d --as-of 2026-10-01T14:00

Repositorio reforzado (backupzit-repo)

ComandoQué hace
backupzit-repo serveEjecuta el servicio (lo hace systemd).
backupzit-repo add-key NAMECrea una clave de acceso (se muestra una vez).
backupzit-repo keys / remove-key NAMEMostrar / revocar claves de acceso.
backupzit-repo fingerprintHuella del certificado para la consola.
backupzit-repo statusDatos guardados y ocultos (borrados, aún conservados).
backupzit-repo undelete --since TIMEVuelve a hacer visibles los archivos borrados desde TIME.

Configuración: /etc/backupzit-repo/repo.env — BACKUPZIT_REPO_LOCK_DAYS, BACKUPZIT_REPO_DATA, BACKUPZIT_REPO_LISTEN, BACKUPZIT_REPO_TLS_HOSTS.

Servidor de gestión (backupzit-server)

Opción / entornoSignificado
--db / BACKUPZIT_DBCadena de conexión de PostgreSQL (obligatoria).
--listen / BACKUPZIT_LISTENDirección HTTPS, por defecto :8443.
--data-dir / BACKUPZIT_DATA_DIRCertificado, secrets.key, descargas de agentes (dist/).
--public-url / BACKUPZIT_PUBLIC_URLURL que usan los agentes y los enlaces de los correos.
--tls-hosts / BACKUPZIT_TLS_HOSTSNombres/IP adicionales para el certificado autofirmado.
BACKUPZIT_ADMIN_PASSWORDContraseña inicial del administrador (solo en el primer arranque).
BACKUPZIT_SECRETS_KEYClave de secretos (base64) en lugar del archivo secrets.key.
--set-admin-password NEWRestablece la contraseña de admin (lo vuelve a habilitar como administrador local) y termina.
--unblock-ip ADDRESS|allLevanta el bloqueo de inicio de sesión de una dirección, o de todas (protección contra fuerza bruta), y termina.
--restore-console --repo R [--snapshot ID]Restaura la consola desde una copia de la consola y termina (consulte Instalar el servidor).
--dev-embedded-db, --dev-http ADDRSolo para evaluación: PostgreSQL privado en el directorio de datos, HTTP sin cifrar en localhost.
--versionMuestra la versión.
