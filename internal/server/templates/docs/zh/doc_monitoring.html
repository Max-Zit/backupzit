监控、报告和日历

一眼看出是否一切都受到保护，查明任意一天发生了什么，并定期向管理层或客户发送报告。

仪表板

最前面的卡片统计受保护的对象：机器（文件、映像和系统备份）、虚拟机、数据库和 NAS 共享（有了之后才显示），每项都有成功的备份。需要关注 列出需要查看的内容：最后一次运行失败的作业、错过计划的作业（自倒数第二次计划运行以来没有成功 —— 会考虑周末和计划的时间窗口）、15 分钟未连接的代理、已满 90 % 或将在 30 天内装满的存储目标（参见 存储目标），以及等待第二个用户批准的更改。如果没有列出任何内容，就说明一切正常。

其他卡片显示在线代理、备份作业、存储目标、排队和正在进行的运行、过去 24 小时的运行、失败和警告，以及待检查的可疑备份（可能是勒索软件，参见 勒索软件防护）。绿色表示正常，黄色需要查看，红色需要处理。下方是最近的活动。

符合 RPO 的作业卡片统计最新正常备份比其恢复点目标更新的作业（参见备份作业）；未达到目标的作业也会列在需要关注下。该列表还会在 admin 账户仍使用生成的初始密码时，以及两台机器使用同一个代理注册时发出警告（参见代理）。从备份运行的虚拟机（即时恢复）会显示在卡片上方，直到完成或丢弃。它还会列出不在任何已启用备份作业中的代理（注册一小时后）。

活动

所有运行，最新的在前。点击某次运行查看详情：处理了什么、统计信息、每个文件的错误，以及（对于备份）还原选项。正在进行的运行会自动刷新。计划运行会显示时钟图标。

正在运行的备份会在其状态下方显示进度，在仪表板、作业页面、活动和运行页面上都可见：带百分比的进度条、已处理的数据量（已知总量时显示占总量的比例，例如磁盘映像和虚拟机）以及文件数。文件备份事先不知道自身大小；其百分比根据该作业上一次备份的文件数和大小估算，并标有 ≈。当备份超过这两者时，只显示数据量和文件数。恢复以同样的方式显示进度；恢复整个备份时显示其大小的百分比。代理在每次轮询时报告进度（运行期间每 15 秒或更频繁）。

运行类型

类型说明
backup作业的文件和文件夹备份。
image-backup磁盘映像备份。
system-backup, system-restoreLinux 系统备份，以及将其还原到磁盘或作为 Proxmox 虚拟机还原。
agent-update从代理页面启动的较新代理版本的安装。
vm-backup, vm-restoreProxmox VE、Hyper-V 和 VMware ESXi 虚拟机（以及 Proxmox 容器）的备份和还原。
vm-instant, vm-instant-finish, vm-instant-discard即时恢复（Proxmox VE、VMware ESXi）：从备份启动的虚拟机，以及完成它（将其磁盘移动或复制到存储）或删除它。
sql-backup, sql-log, sql-restore数据库备份（SQL Server、PostgreSQL、MySQL/MariaDB）、其日志备份以及数据库还原。
vm-replica, vm-replica-start虚拟机备份后的 Proxmox 复制，以及启动副本（故障转移）。
vm-file-restore从 Proxmox、Hyper-V 或 VMware 备份中的虚拟机磁盘复制到代理的文件。
copy备份复制作业：将另一个作业的备份复制到第二个存储。
verify自动或手动的还原测试。
restore, image-restore, image-file-restore还原文件、整块磁盘或映像中的文件。
repo-check数据检查：代理读取存储库中的所有数据并进行验证（参见还原）。
agent-log代理应请求发送的日志（代理页面上的获取日志）。

日历

日历 每次显示一个月：

  • 过去的日子 显示实际运行的内容 —— 备份和复制 —— 按结果着色（绿色、黄色、红色）。同一作业在同一天的多次运行会合并，例如 08:00 办公文件 ×6。
  • 未来的日子 显示计划将要启动的内容（蓝色）。
  • 条目很多的日子会显示四条和 +N 更多；点击查看全部，再次点击收起。
  • 未来 7 天 按顺序列出每次即将进行的运行。

按代理筛选可查看某台机器的计划。点击条目可打开作业。“每次备份后”运行的复制作业会显示在其源作业运行的日子。

报告

报告 可汇总任意时段：今天、昨天、过去 7/30/90 天、本周或上周、本月或上月，或自定义日期范围 —— 针对所有代理、某个代理或某个作业。

  • 备份次数、成功率、成功 / 有警告 / 失败的运行、读取和上传的数据、还原、还原测试（以及失败的测试）、可疑备份。
  • 每日备份图表。
  • 每个作业：运行次数、成功率、最后结果、最近成功备份、受保护大小、上传数据以及最新还原测试的结果。在该时段内没有成功备份的作业会突出显示。
  • 所有失败、警告和可疑备份及其消息。

使用 CSV 在 Excel 中打开所有运行（防公式注入），使用 打印 / PDF 生成文档，或使用 通过电子邮件发送此报告。监控工具也可以通过 REST API（/api/v1/report）获取相同的数据。

PDF 以您的语言生成可直接发送的 A4 报告——供主管或客户使用：总计、每日备份图表、包含成功率和最近一次正常备份的所有作业表格，以及该期间的问题。通过电子邮件发送的报告（通过电子邮件发送此报告和计划报告）附带 PDF 和 CSV。

计划报告

在 计划报告 下创建在时段结束时自动通过电子邮件发送的报告：

  • 每日 —— 每天早上，关于前一天。
  • 每周 —— 每周一，关于上一周。
  • 每月 —— 每月 1 日，关于上个月（非常适合客户或管理层）。

选择小时、范围（所有代理、某个代理或某个作业）和收件人（留空 = 通知收件人）。附件中包含 PDF 报告和所有运行的 CSV。必须在 设置 → 电子邮件通知 中配置电子邮件。创建和删除计划报告需要备份操作员或管理员角色。
