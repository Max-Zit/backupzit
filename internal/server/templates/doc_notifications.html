Email notifications

Get an email when a backup fails, and a daily summary every morning.

Setting up email

Under Settings → Email notifications:

FieldExample
SMTP server / portsmtp.office365.com / 587, smtp.gmail.com / 587, internal relay / 25
SecuritySTARTTLS (port 587), TLS (port 465) or none (internal relay only)
User / passwordThe mailbox used to send; leave empty for an anonymous relay. Microsoft 365 and Gmail need an app password.
Senderbackup@example.com
RecipientsOne or more addresses, comma separated.

Use Send test email to check the settings.

What is sent

  • Failures (recommended) — one email per failed run with the reason.
  • Warnings — runs where some files could not be read.
  • Successes — every successful run (usually too much; prefer the daily report).
  • Daily report — at the chosen hour: runs of the last 24 hours, problems and offline agents. Subject starts with OK, WARNINGS or ATTENTION, so mail rules can sort them.

For weekly or monthly summaries use scheduled reports.
