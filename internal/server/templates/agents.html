VMware ESXi hosts

Nothing is installed on ESXi: an agent on any machine in the network works as its proxy. It snapshots the VMs, reads their disks from the host and writes the backups to the storage. Choose an agent close to the ESXi host and the storage, ideally on the same fast network.
