Command line reference

The agent also works on its own from the command line — for scripting, for restoring without the console, and for emergencies.

Repository and credentials

Every command takes --repo (or BACKUPZIT_REPO). Prefer environment variables for secrets:

LocationCredentials
D:\Backups\pc1, /mnt/backup/pc1—
sftp://user@host:22/pathBACKUPZIT_SFTP_PASSWORD or --sftp-key file; --sftp-hostkey SHA256:…
s3://endpoint/bucket/prefix (?tls=false for HTTP)BACKUPZIT_S3_ACCESS_KEY, BACKUPZIT_S3_SECRET_KEY, --s3-region
smb://[domain;]user@host/share/pathBACKUPZIT_SMB_PASSWORD
hardened://host:8500/pathBACKUPZIT_HARDENED_KEY, BACKUPZIT_HARDENED_FINGERPRINT
azure://account/container/pathBACKUPZIT_AZURE_KEY or BACKUPZIT_AZURE_SAS

Encrypted repositories need the recovery key in BACKUPZIT_PASSWORD.

Agent commands

CommandWhat it does
initCreate a new repository.
backup [--vss] PATH…Back up files and folders.
snapshotsList snapshots.
ls SNAPSHOT [PATH]List files in a snapshot.
restore --target DIR [--include PATH] [--verify] SNAPSHOT|latestRestore files (--original writes them back to their original location).
check [--read-data]Verify the repository; with --read-data every byte is read and checked.
disksShow disks and partitions.
image-backup --disk N [--partitions 1,2]Back up a disk image.
image-restore --target-disk N --yes-erase-target [--keep-offline] SNAPSHOTWrite an image to a disk (destroys its contents).
image-ls, image-extractBrowse and extract files from an image.
enroll --server URL --token T --fingerprint FConnect the agent to a console.
service install|start|stop|uninstallManage the agent service.

Read-only point-in-time view of immutable storage: add --as-of 2026-10-01T14:30 to snapshots, ls or restore.

Examples

set BACKUPZIT_PASSWORD=XXXX-XXXX-...
set BACKUPZIT_S3_ACCESS_KEY=...
set BACKUPZIT_S3_SECRET_KEY=...
backupzit-agent snapshots --repo s3://s3.wasabisys.com/company-backups/backupzit/pc1_1a2b3c4d
backupzit-agent restore --repo s3://s3.wasabisys.com/company-backups/backupzit/pc1_1a2b3c4d --target D:\Restore --include C:\Users\ana\Documents latest
backupzit-agent check --repo s3://... --read-data

Hardened repository commands

CommandWhat it does
backupzit-repo add-key NAMECreate an access key (shown once).
backupzit-repo keys / remove-key NAMEList / revoke access keys.
backupzit-repo fingerprintCertificate fingerprint for the console.
backupzit-repo statusStored and hidden (deleted, still retained) data.
backupzit-repo undelete --since TIMEMake files deleted since TIME visible again.

Server commands

CommandWhat it does
set -a; . /etc/backupzit/server.env; backupzit-server --set-admin-password NEW-PASSWORDReset the password of the admin user and sign out its sessions.
systemctl status backupzit-server, journalctl -u backupzit-serverService state and log.
