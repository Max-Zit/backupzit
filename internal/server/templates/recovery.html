Recovery

Bare-metal restore

  1. Boot the machine to restore from a BackupZit recovery ISO (or a USB stick made from it): the Windows recovery ISO for disk images of Windows machines, the Linux recovery ISO for Linux system backups.
  2. It connects to this server using \backupzit\recovery.json from the boot media, or asks for the server address and a recovery code.
  3. The machine appears below and under Agents as a recovery agent, with its disks.
  4. Open the backup in Activity: for a disk image choose “Restore this image to a disk”, for a Linux system backup “Restore the whole system — onto a disk” with the recovery agent and its disk (e.g. /dev/sda).
  5. When the restore has finished, remove the boot media and restart the machine.
