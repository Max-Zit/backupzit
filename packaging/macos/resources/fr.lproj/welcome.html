Agent BackupZit

Ce programme installe l’agent BackupZit, qui sauvegarde ce Mac selon les instructions de votre console BackupZit :

  • l’agent, un service en arrière-plan : /Library/BackupZit/bin/backupzit-agent
  • l’app BackupZit de la barre des menus, qui montre l’état des sauvegardes : /Applications/BackupZit.app

Pour inscrire ce Mac pendant l’installation, placez le code d’inscription (BZ1-..., dans la console : Agents > Créer un jeton d’inscription) dans un fichier nommé backupzit-enroll.txt à côté de ce programme d’installation. Vous pouvez aussi l’inscrire plus tard.

À la fin, macOS a besoin de votre accord pour quelques autorisations : la dernière page vous montre comment faire, étape par étape.
