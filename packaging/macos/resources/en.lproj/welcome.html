BackupZit Agent

This installs the BackupZit agent, which backs up this Mac as instructed by your BackupZit console:

  • the agent, a background service: /Library/BackupZit/bin/backupzit-agent
  • the BackupZit menu bar app, which shows the state of the backups: /Applications/BackupZit.app

To enroll this Mac while installing, put the enrollment code (BZ1-..., in the console: Agents > Create enrollment token) in a file named backupzit-enroll.txt next to this installer, in a folder only you can change. It counts only on a Mac not enrolled yet: an update never moves the Mac to another console. You can also enroll later.

At the end, macOS needs your approval for a few permissions: the last page shows you how, step by step.
