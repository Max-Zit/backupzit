The BackupZit agent is installed

macOS lets only you grant the permissions below. Without Full Disk Access, backups silently miss protected folders (Mail, Messages, Safari, Desktop and Documents of other users, app data).

1. Give the agent Full Disk Access

  1. Open System Settings > Privacy & Security > Full Disk Access.
  2. Click the + button below the list and enter your password.
  3. In the window that opens, press Command-Shift-G, type /Library/BackupZit/bin/backupzit-agent and press Return, then click Open.
  4. Check that the switch next to backupzit-agent is on.

Instead of the + button you can drag the file into the list: in the Finder choose Go > Go to Folder…, type /Library/BackupZit/bin, then drag backupzit-agent onto the Full Disk Access list.

2. Allow the agent in the background

  1. macOS shows the notification “Background Items Added”: the agent is a background service and must stay allowed.
  2. Open System Settings > General > Login Items & Extensions.
  3. Under Allow in the Background, check that backupzit-agent and BackupZit are switched on.

3. Allow notifications

  1. When the BackupZit menu bar app asks to send notifications, click Allow.
  2. Later: System Settings > Notifications > BackupZit, switch on Allow notifications. BackupZit tells you there when a backup fails.

4. The menu bar app checks it for you

The BackupZit icon is now in the menu bar. Its assistant checks each of these permissions, shows what is still missing and opens the right page of System Settings. The agent also reports a missing permission to your BackupZit console.

Not enrolled yet?

If you did not provide an enrollment code, copy one from the console (Agents > Create enrollment token) and run in Terminal:
sudo /Library/BackupZit/bin/backupzit-agent enroll --code BZ1-...
The agent is already running and starts working as soon as it is enrolled.

To remove BackupZit later: sudo /Library/BackupZit/uninstall.sh
