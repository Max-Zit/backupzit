Open-source, self-hosted backup for servers, PCs, virtual machines and Microsoft 365

BackupZit backs up Windows and Linux machines, Proxmox VE, VMware ESXi and Hyper-V virtual machines, SQL Server, PostgreSQL and MySQL databases, NAS shares and Microsoft 365 — managed from one web console that runs on your own server. Free under the AGPLv3.

What BackupZit backs up

Windows and Linux files

Incremental file backup, from a VSS snapshot on Windows, so open files are consistent. Restore single files from the browser.

Whole disks and bare metal

Disk images of Windows PCs and servers and full Linux system backups, restored from a recovery ISO — also onto different hardware.

Proxmox VE backup

Agentless backup of Proxmox VMs and containers with changed blocks only, instant recovery, replication and automatic boot tests.

VMware ESXi backup

Agentless VMware backup with changed block tracking through a proxy agent, restore as a new VM or in place, instant recovery over NFS.

Hyper-V backup

Agentless Hyper-V VM backup with resilient change tracking, restored to the same or another Hyper-V host.

Databases

SQL Server, PostgreSQL and MySQL/MariaDB with their native tools, log backups and point-in-time restore of a single database.

NAS shares

SMB and NFS shares read by any agent — nothing has to be installed on the NAS.

Microsoft 365 backup

Exchange Online mail, calendars and contacts, OneDrive and SharePoint through Microsoft Graph with read-only permissions.

Why BackupZit

Install in minutes

Import the ready-made appliance (OVA for VMware, qcow2 for Proxmox/KVM, VHDX for Hyper-V, generation 1), boot the appliance ISO, or install on an existing Debian, Ubuntu, AlmaLinux or Rocky Linux server:

curl -fsSL https://github.com/Max-Zit/backupzit/releases/latest/download/install.sh | sudo sh

Then open https://<server>:8443, sign in and add agents: an MSI for Windows, deb/rpm packages for Linux. Requirements: 2 vCPU, 2–4 GB RAM and a 16–20 GB disk for the console.

Frequently asked questions

Is BackupZit free?

Yes. BackupZit is free and open source under the GNU AGPLv3, with no limits on machines, VMs or storage. MaxZit offers optional commercial support.

Can BackupZit back up Proxmox VE, VMware ESXi and Hyper-V virtual machines?

Yes. Proxmox VE VMs and containers, VMware ESXi VMs and Hyper-V VMs are backed up agentless with changed-block tracking, and can be restored as new VMs. Proxmox and VMware VMs can also start directly from the backup (instant recovery).

Where are the backups stored?

On storage you choose: SFTP servers and NAS, S3-compatible storage (AWS, Wasabi, Backblaze B2, MinIO), SMB shares, Azure Blob Storage, rotating USB disks, local disks or the BackupZit hardened repository. Backups are deduplicated, compressed and encrypted with AES-256.

Does BackupZit protect against ransomware?

Backups can be immutable (S3 Object Lock or the write-once hardened repository), suspicious backups that look like ransomware or mass deletion are detected and retention pauses automatically, and restore tests check that backups can really be restored.

Does BackupZit need the cloud or an internet connection?

No. Every organization runs its own console in its own network; there is no cloud service and nothing has to be exposed to the internet.
